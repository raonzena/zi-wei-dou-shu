# ADR-0005: 무주성 궁은 대궁 주성을 참고해 풀이

- 상태: 채택
- 결정일: 2026-09-13

## 결정

명궁과 열두 궁에 주성이 없으면 맞은편 궁의 주성을 참고해 기본 풀이를 제공한다. 본궁과 지지상 여섯 칸 떨어진 궁을 대궁으로 찾고, 그 궁에 실제 놓인 주성의 단일 별 기본 의미를 사용한다.

화면에는 본궁에 주성이 없다는 사실, 맞은편 궁 이름, 참고한 주성을 함께 표시한다. 대궁의 주성을 본궁에 실제 놓인 주성처럼 저장하거나 표시하지 않으며, 대궁의 생활 영역이 본궁에 그대로 적용된다고 단정하지 않는다. 보조성·사화·밝기·삼방사정을 종합한 전문 조합 풀이로 확대하지 않는다.

## 근거

프로젝트에 고정된 iztro 2.6.1은 명궁 주성 조회 함수에서 명궁이 공궁이면 인덱스에 6을 더한 대궁의 주성을 반환한다. 같은 버전의 `surroundedPalaces`도 대상 궁의 지지 위치에 6을 더해 대궁을 계산한다. 서비스 Chart는 엔진 인스턴스 대신 검증된 JSON만 보관하므로 동일한 지지 순서와 `+6` 규칙을 순수 함수로 적용한다.

iztro의 자동 차용은 명궁 주성 조회에서 명시적으로 확인된다. 다른 궁은 iztro가 제공하는 대궁 관계 계산을 사용하되, 해석의 정확성을 과장하지 않도록 모두 ‘참고 풀이’로 구분한다.

## 영향

- ADR-0004의 “주성이 없으면 대궁의 별을 빌리지 않는다”는 결정은 이 결정으로 대체한다.
- 종합 풀이의 명궁 기본 풀이, 일곱 생활 분야, 상세 명반의 선택한 궁에 동일한 대궁 위치 규칙을 적용한다.
- 규칙 기반 풀이 버전을 `ming-major-v5`로 올려 새 결과의 중복 판별에 반영한다.
- 기존 저장 결과 스키마는 대궁 근거 필드를 선택 항목으로 받아 계속 읽을 수 있다.

## 한계

대궁 주성의 기본 의미를 참고하는 기능이며 무주성 궁의 전체 해석을 완성한 것은 아니다. 학파별 공궁 판정 예외, 별의 밝기, 본궁의 보조성, 사화와 삼방사정을 결합하는 규칙은 이번 범위에 포함하지 않는다.
