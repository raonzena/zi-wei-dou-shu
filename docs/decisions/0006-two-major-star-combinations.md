# ADR-0006: 두 주성의 조합을 별도 규칙으로 설명

- 상태: 채택
- 결정일: 2026-09-13

## 결정

한 궁에 주성이 둘이면 한 별을 대표로 고르거나 두 별의 개별 설명만 나열하지 않는다. 종합 풀이에서는 두 성향이 함께 만드는 핵심 특징·강점·주의점·균형점을 쉬운 말로 요약한다. 상세 명반에서는 `각 별의 의미 → 두 별이 함께 만드는 특징 → 해당 궁의 생활 영역에서 나타나는 모습` 순서로 설명한다.

iztro 2.6.1의 실제 배치를 표본 계산해 확인한 24개 동궁 조합을 명시적인 콘텐츠 규칙으로 관리한다. 각 조합은 기존에 iztro 14주성 설명을 바탕으로 검수한 단일 별 의미 두 개를 함께 연결한 서비스 작성 문장이다. 밝기·사화·보조성과 학파별 해석까지 결합한 전문 조합 풀이로 소개하지 않는다.

## 근거

기존 화면은 두 주성을 각각 설명해 사용자가 두 성향의 관계를 스스로 조합해야 했다. 사용자는 종합 풀이에서 조합의 핵심을 쉽게 요약하고, 상세 명반에서 개별 의미와 조합, 생활 영역의 적용을 단계적으로 보여주도록 요청했다.

iztro는 명반 계산 결과에 궁별 주성 배열을 제공하지만 동궁 조합의 자연어 해석은 제공하지 않는다. 따라서 발생 가능한 조합 집합은 iztro 2.6.1 계산 결과를 기준으로 제한하고, 문장 의미는 프로젝트가 이미 검수한 단일 별 규칙을 넘지 않도록 구성한다.

## 영향과 한계

- 규칙에 없는 두 주성 조합은 일부 설명을 조용히 제공하지 않고 오류로 처리한다.
- 무주성 궁이 대궁의 두 주성을 참고할 때도 같은 조합 규칙을 사용하되 대궁 참고임을 표시한다.
- 이전 저장 결과에 조합 필드가 없어도 읽을 수 있도록 필드는 선택적으로 파싱하고 `null`로 정규화한다.
- 조합 규칙의 코드 검증은 문장의 점술적 정확성이나 독립적인 전문가 검수를 뜻하지 않는다.
