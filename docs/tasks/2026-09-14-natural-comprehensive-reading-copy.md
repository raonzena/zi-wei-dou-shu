# 종합 풀이의 자연스러운 성향 문장

- 작성일: 2026-09-14
- 최종 갱신일: 2026-09-14
- 상태: 구현·로컬 검증 완료

## 작업 개요

종합 풀이에서 가능성과 태도를 반복해서 언급해 사용자가 자신의 성향을 바로 이해하기 어려운 문제를 개선한다. 일곱 분야의 열두 궁 본문을 성향부터 직접 설명하는 자연스러운 한국어로 바꾸고, 관계와 생활에서 나타나는 방식과 부담이 생기는 지점을 구체적으로 전달한다.

## 요구사항

- REQ-03 / REQ-05: 각 궁의 첫 문장부터 사용자의 성향을 분명하게 설명한다.
- REQ-07: `fluent-korean` 규칙을 다른 문체와 분량 규칙보다 우선한다.
- `~할 수 있습니다`, `~하는 태도가 두드러집니다`, `~이 드러납니다`처럼 해석을 모호하게 만드는 문장을 반복하지 않는다.
- 주성이 둘이면 두 별을 한 문장 안에서 자연스럽게 연결하고, 주성이 없는 궁은 기존 맞은편 궁 참고 기준을 유지한다.
- iztro 원문에서 확인한 동궁 조합과 설명 범위, 근거 표시는 변경하지 않는다.

## 결정과 근거

- 문제 문장은 Supabase의 `star_content`가 아니라 `src/domain/interpretation/comprehensive-reading.ts`의 공통 문장 생성 규칙에서 만들어졌다. 따라서 운영 DB는 수정하지 않는다.
- 가족과 대인관계만 수정하면 같은 표현이 다른 분야에 남으므로 열두 궁의 본문 규칙을 함께 정리한다.
- 가능성을 모두 단정문으로 바꾸는 대신 성향은 직접 설명하고, 과도해질 때 생기는 부담은 `~하기 쉽습니다`처럼 경향의 범위를 남긴다.
- 주성, 무주성, 맞은편 궁과 삼방사정은 계산·근거 데이터이므로 기존 로직을 유지한다.

## 변경 내용과 영향

- 14주성의 맥락 문장을 명사형 `태도` 나열에서 완결된 행동 문장으로 변경했다.
- 두 주성은 `첫 별의 방식으로 행동하면서 두 번째 별의 특징도 함께 보이는 문장`으로 연결한다.
- 열두 궁의 강점, 부담과 생활 장면을 직접적이고 구체적인 표현으로 교체했다.
- 건강과 컨디션은 수면·휴식·피로와 생활 리듬만 다루고, 일과 커리어는 계획·마감·책임을 다루는 기존 영역 구분을 유지했다.
- 화면 구조, 문장 수, 근거 영역과 DB 콘텐츠는 변경하지 않았다.

## 요구사항 대조

- 종합 풀이의 분야 순서와 궁 연결은 유지했다.
- 궁마다 네 문장을 제공하는 구조와 구체적인 생활 장면을 유지했다.
- 무주성은 맞은편 궁의 주성을 참고하고 본궁 주성처럼 표시하지 않는 기존 기준과 일치한다.
- 본문은 성향을 먼저 설명하며, 행동 권유와 화면 구조 설명을 추가하지 않았다.

## 남은 문제와 추후 개선점

- 보조성 설명은 별도로 관리하는 Supabase 발행 콘텐츠이므로 이번 작업에서 수정하지 않았다.
- 실제 명반마다 주성 순서와 조합이 달라진다. 이번 규칙은 관련 테스트와 사용자 제시 사례의 네 궁 조합을 기준으로 문장을 검토했으며, 배포 전 미리보기에서 전체 문맥을 다시 확인할 필요가 있다.
