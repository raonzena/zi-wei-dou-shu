# 풀이 예시 확장과 한국어 문장 교정

- 작성일: 2026-09-13
- 최종 갱신일: 2026-09-13
- 상태: 구현·운영 DB 발행 완료

## 작업 개요

상세 명반과 AI 풀이에 남아 있던 `4~5문장` 분량 기준을 `7~8문장`으로 바꾸고, 해석한 성향이 생활에서 어떻게 나타날 수 있는지 보여주는 예시를 추가한다. 간편 종합 풀이는 현재의 짧은 구성을 유지한다. Supabase에 발행된 한국어 별 설명 39개도 fluent-korean 원문 규칙에 따라 검토하고, 어색한 문장만 새 버전으로 교정한다.

## 요구사항

- `docs/requirements.md`의 종합 풀이, 상세 명반, AI 해석, 별 설명 관리 요구사항을 따른다.
- 상세 명반의 각 별 의미, 두 별 조합, 궁의 생활 모습과 활용 방법은 각각 7~8문장으로 설명하고 생활 예시를 포함한다.
- AI의 일곱 분야 본문도 각각 7~8문장으로 작성하고, 근거에서 이어지는 가상의 생활 예시를 최소 한 문장 포함한다.
- 간편 종합 풀이의 조합 요약은 길어지지 않아야 한다.
- 한국어 문장은 fluent-korean 원문 지침을 다른 문체·분량 규칙보다 우선해 적용한다.
- DB 문구는 iztro에서 가져온 기존 의미와 출처를 유지하고, 발행본을 직접 수정하지 않으며 새 버전을 검수·발행한다.

## 결정과 근거

- 프로젝트 작업 문서가 가리키는 fluent-korean 원문을 다시 확인했다. 필요한 문장 성분과 조사·어미를 생략하지 않고, 본문을 완결된 문장으로 쓰며, 문맥에 맞는 어휘를 사용하고 불필요한 비유와 엠대시를 피하는 규칙을 최상위 한국어 규칙으로 명문화했다.
- 상세 풀이는 기존의 단일 별 규칙과 iztro 2.6.1에서 확인한 24개 두 주성 배치 조합을 그대로 근거로 사용한다. 예시는 기존 의미를 새로운 사건 예측으로 확대하지 않고, 해당 성향을 이해하기 위한 가상의 생활 상황으로 작성한다.
- 운영 DB에서 현재 발행된 한국어 별 설명 39개를 모두 조회했다. 직접적인 생활어로 이미 자연스러운 7개는 유지하고, `성향을 나타냅니다`, `~로 읽습니다`, `함께 살펴봅니다`처럼 해설 과정이 반복되거나 주체가 흐려진 32개를 교정 대상으로 정했다.

## 변경 내용과 영향

- 상세 궁 풀이에 12궁별 상황·활용 예시, 14주성별 예시, 24개 두 주성 조합별 예시를 추가했다.
- 상세 화면은 `각 별의 의미 → 두 별이 함께 만드는 특징 → 해당 궁의 생활 영역에서 나타나는 모습` 순서를 유지하면서 각 항목을 7~8문장으로 표시한다.
- AI 프롬프트와 품질 평가는 분야별 7~8문장과 생활 예시를 요구한다. 프롬프트 버전을 `grounded-passages-v7`로 올렸다.
- 별 설명 교정 마이그레이션은 기존 발행본과 iztro 출처를 보존하며 교정본을 새 버전으로 만들어 검수·발행한다.
- 간편 종합 풀이가 사용하는 짧은 문장은 변경하지 않았다.

## 검증

- `prettier --check .`: 통과했다.
- `eslint . --max-warnings=0`: 통과했다.
- `next typegen`과 `tsc --noEmit`: 통과했다.
- `vitest run`: 테스트 298개가 통과했고 1개는 기존 조건에 따라 제외됐다.
- `next build --webpack`: 운영 빌드가 통과했다.
- 사용자 확인 후 운영 DB에 마이그레이션을 적용했다. 한국어 발행본 39개와 서로 다른 별 39개가 유지됐고, 새 교정본은 32개였다. 교정 대상으로 정한 반복 해설 표현은 발행본에서 0건이었다.
- 교정본 32개 모두에서 이전 발행본이 보관됐고, source_url·source_version·source_text·license가 이전 버전과 일치했다.

## 요구사항 대조

코드와 기준 문서는 7~8문장과 생활 예시 요구사항으로 갱신했다. 간편 풀이의 짧은 문장과 두 주성 조합 요약도 유지됨을 테스트로 확인했다. 운영 DB 교정본도 버전 이력과 출처를 보존해 발행했으므로 이번 작업의 요구사항과 일치한다.

## 남은 문제와 추후 개선점

- 실제 AI는 운영에서 비활성화되어 있으므로 새 프롬프트의 의미 품질 실호출은 이번 작업 범위에서 검증할 수 없다.
