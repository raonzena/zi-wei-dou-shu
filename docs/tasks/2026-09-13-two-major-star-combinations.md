# 두 주성 조합 풀이

- 작성일: 2026-09-13
- 최종 갱신일: 2026-09-13
- 상태: 구현·검증 완료

## 작업 개요

주성이 두 개인 궁에서 별 하나를 대표로 고르거나 개별 의미만 나열하지 않고 조합의 핵심을 설명한다. 종합 풀이는 쉬운 조합 요약을 제공하고, 상세 명반은 각 별·조합·궁의 생활 맥락을 단계적으로 보여준다.

## 요구사항

- REQ-03 / REQ-05: 두 주성의 핵심 특징을 쉬운 말로 요약한다.
- REQ-04: 각 별의 의미, 두 별이 함께 만드는 특징, 궁의 생활 영역에서 나타나는 모습 순서를 지킨다.
- iztro 2.6.1에서 발생 가능한 동궁 조합을 구현 범위의 기준으로 사용한다.

## 결정과 근거

iztro 2.6.1 계산 결과를 여러 날짜와 시각에서 추출해 발생 가능한 두 주성 조합 24개를 확인했다. 조합 규칙은 기존의 iztro 기반 단일 별 콘텐츠에서 공통 강점과 긴장 지점을 연결해 작성한다. iztro가 조합 자연어 해석을 제공하는 것으로 오인하지 않도록 출처와 서비스 작성 범위를 구분한다.

자세한 결정은 ADR-0006에 기록한다.

## 변경 내용과 영향

- iztro 2.6.1 계산에서 확인한 두 주성 동궁 조합 24개에 조합별 요약·강점·주의점·균형점을 추가했다.
- 간편 종합 풀이는 두 별 중 하나를 대표로 고르지 않고 조합의 핵심 특징을 쉬운 말로 보여준다.
- 상세 명반은 각 별의 의미를 먼저 보여준 다음 조합의 특징과 해당 궁의 생활 영역에서 나타나는 모습을 차례로 보여준다.
- 무주성 궁이 맞은편 궁의 두 주성을 참고할 때도 같은 조합 풀이를 사용한다.
- 저장된 과거 결과에 조합 필드가 없어도 불러올 수 있도록 결과 스냅샷 변환을 이전 형식과 호환되게 유지했다.
- 명궁 기본 풀이의 내용 버전을 `ming-major-v6`으로 올렸다.

## 요구사항 대조

- 종합 풀이에서 두 주성이면 개별 별 풀이 대신 조합의 핵심 특징을 표시한다.
- 상세 명반에서 `각 별의 의미 → 두 별이 함께 만드는 특징 → 궁의 생활 영역에서 나타나는 모습` 순서를 지킨다.
- 주성이 하나인 궁의 기존 풀이와 간편 명반의 기존 선택 동작은 유지한다.

## 남은 문제와 추후 개선점

- iztro는 별 배치와 맞은편 궁 관계의 계산 기준이며 조합의 자연어 해석을 직접 제공하지 않는다. 조합 문장은 서비스가 기존 별 의미를 바탕으로 작성한 것으로, 향후 별 밝기·보조성·사화까지 포함하는 전문 합성 해석은 별도 검증이 필요하다.
