# 테스트 코드 중복 점검

- 작성일: 2026-09-13
- 최종 갱신일: 2026-09-13
- 상태: 구현·검증 완료

## 작업 개요

전체 테스트 규모와 최근 종합 풀이 테스트의 역할을 확인하고, 같은 동작을 반복하거나 선언값을 그대로 검사하는 코드를 제거한다.

## 요구사항

- 계산 경계, 무주성 대궁 참조, 명궁 중복 방지와 UI 출력처럼 실제 회귀를 막는 테스트는 유지한다.
- 문구 데이터의 형태만 반복해서 확인하거나 이미 같은 계층에서 검증한 테스트는 제거한다.

## 결정과 근거

전체 테스트는 3,772줄, 298개로 테스트 한 개당 평균 약 13줄이었다. 전체 규모보다 이번 PR에서 추가된 종합 풀이 테스트의 책임 중복이 문제였다. 도메인 테스트에서는 열두 궁의 배치와 대궁 참조를 이미 반복문으로 검증하고 있었으므로 같은 내용을 다시 검사한 무주성 테스트를 제거했다. 문구가 실제 화면에서 사라졌는지는 UI 테스트 한 곳에서만 확인하도록 정리했다.

## 변경 내용과 영향

- 종합 풀이 도메인 테스트에서 질문의 문장 부호, 예시 접두어와 객체 속성처럼 선언을 반복한 단언을 제거했다.
- 같은 파일에서 무주성 대궁 참조를 중복 검증하던 테스트 한 개를 제거했다.
- UI에서 제외 문구 네 개를 하나의 정규식 단언으로 통합했다.
- 명궁 중복 방지와 직접 관련 없는 질문 제목 단언을 제거했다.

## 검증

- 관련 테스트 파일은 196줄에서 161줄로 줄었다.
- `prettier --check .`, `eslint .`: 통과했다.
- `next typegen`, `tsc --noEmit`: 통과했다.
- `vitest run`: 분야 혼합 회귀 테스트를 포함한 테스트 298개가 통과했고 1개는 기존 설정대로 제외됐다.
- `pnpm run build`: Webpack 운영 빌드가 통과했다.

## 요구사항 대조

무주성 대궁 계산은 종합 풀이 도메인 테스트에서 열두 궁 전체를 대상으로 유지하고, 실제 근거 문구는 UI 테스트에서 유지한다. 명궁 조합의 중복 방지 검증도 유지한다.

## 남은 문제와 추후 개선점

다른 테스트 파일은 서로 다른 계산 경계나 서버 오류를 검증하고 있어 이번 작업에서는 제거하지 않았다.
