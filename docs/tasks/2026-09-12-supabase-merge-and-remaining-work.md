## 작업 개요와 요구사항

사용자가 Supabase 연결 완료를 알리고 PR 머지와 남은 작업 정리를 요청했다. PR #2의 변경·CI·병합 가능 상태를 확인하여 main에 스쿼시 머지했다. 요구사항의 현재 해석·운영 정책과 미구현 목록을 기준으로 후속 작업을 구분한다.

## 결정과 근거

PR은 공개 가능한 프로젝트 URL, Supabase 테이블·RPC·Cron과 Vercel 설정 확인 기록, 독립 명반 테스트의 타임아웃 조정을 담고 있다. 테스트 assertion은 변경하지 않았다. PR validate와 Vercel Preview가 성공했고 충돌은 없었다. 스쿼시 커밋 제목·본문을 저장소 규칙에 맞췄다.

머지 커밋은 `d7d033b457b7daea381cb98dff2b3d291322648c`다. Supabase 원격 구성 확인은 사용자와 PR의 실행 기록을 근거로 하며 이번 작업에서 원격 DB를 다시 검사하지 않았다. 공유 ChatGPT 링크는 읽기 도구에서 본문을 가져오지 못했다.

## 남은 작업과 권장 순서

아래 순서는 착수 제안이며 새 기능·정책의 확정이나 구현 완료를 뜻하지 않는다.

AI 의미 검증은 현재 본명반 해석을 대상으로 한다. 대한·유년·유월 AI 해석과 이전 12단계 형식은 현재 요구사항에서 제외되었으므로 미구현 기능으로 되살리지 않는다. 운한 계산 자료는 상세 명반에 계속 제공한다.

초기에는 호출·비용 리포트를 수동으로 확인한다. 실제 운영량이 생긴 뒤 자동 경보와 한도 조정을 검토할 수 있다. 궁·별 조합의 종합 풀이, 자체 TypeScript 계산 엔진과 윤달 늦은 자시 정책 변경은 별도 검토가 필요한 후속 개선이며 이번 출시 필수 작업으로 추가하지 않는다.

## 변경과 검증

- PR #2 머지와 로컬 main fast-forward 동기화 완료.
- PR CI와 diff를 확인했으며 비밀키 값이 포함되지 않은 것을 확인했다.
- 이번 정리에서는 애플리케이션·DB·환경변수를 변경하지 않았고 유료 AI를 호출하지 않았다.
- main의 포맷·린트·타입·테스트·DB 검증·운영 빌드와 Vercel 자동 배포가 성공했다. 공개 사이트 HTTP 200과 AI 요청용 입력값이 없는 상태를 확인했다.
- 이 후속 정리 문서와 목록 갱신은 로컬 변경이며 머지된 PR에는 포함되지 않는다.
