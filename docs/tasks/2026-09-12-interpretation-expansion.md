# 해석 근거 확장과 AI 검증

- 상태: 구현·검증 완료. AI 해석 품질의 출시 판정은 미통과.
- 관련 요구사항: REQ-03·04·07·08, 사용자 해석 확장 요청

## 범위와 결정

올해 전체 유월을 윤달 전반·후반까지 제공한다는 사용자 선택을 반영한다. iztro 2.6.1의 monthlyList(year, true), mutagedPlaces, 운한 stars를 사용한다. 명반 엔진과 한국 출생 정규화 정책은 유지한다.

자부동궁·자부협명은 공식 설명에 명시된 명궁 배치 조건만 검사한다. 전체 격국의 길흉 판정으로 확대하지 않는다. 보조성은 천마·지공·지겁과 교류 관련 잡요 네 개를 추가한다.

## 검증과 요구사항 대조

- 원본 상담 프롬프트는 HEAD와 직접 비교해 변경 없음 확인. 서비스 적용 규칙만 v4→v5로 확장했다.
- pnpm check: 포맷·린트·타입과 179개 테스트 통과. pnpm build 및 git diff --check 통과.
- 2025 윤6월 1~~15일·16~~29일, 23시 출생 월 목록, 사궁 무곡 화록 자화와 유궁 탐랑 화권, 48개 별·도착 궁 연결, 두 격국의 양성·음성 조건을 검사했다.
- 10개 천간 검사를 개별 테스트로 나눴다. 10회 명반을 계산하는 언어·요청 격리 검사는 전체 유월 계산이 추가돼 기본 5초를 넘으므로 해당 테스트만 20초로 지정했다. 계산·격리 단언은 유지했다.
- 브라우저 모의 응답에서 12개 유월 표, 새 근거 ID 렌더링, 사화와 격국 펼침, 유요 툴팁을 확인했다. 972px 뷰포트에서 문서 너비도 972px로 페이지 가로 넘침이 없었다. 모바일 별도 실기기 검증은 수행하지 않았다.
- 첫 실호출(v4): HTTP 200, 약 50.5초, 입력 22,197 / 출력 9,099토큰, 캐시 0. 구조 검증은 통과했지만 읽기 검토에서 유월 자료 부재라는 모순, 내부 ID 노출, 본명반 별이 재배치된다는 부정확한 표현을 발견했다. 정상 품질로 판정하지 않았다.
- v5는 지원 범위 일치·사용자용 시기 이름·본명반과 유요 구분을 강화했다. 월별 ID 전체 포함 검사와 관찰한 부재 문구·내부 ID 노출의 회귀 거부 검사를 추가했다. 정규식은 관찰한 오류를 막는 제한된 검사이며 의미 전체를 검증하지 않는다.
- 두 번째 실호출(v5): HTTP 200, 약 58.4초, 입력 22,484 / 캐시 입력 6,912 / 출력 8,961토큰. 이전 모순·내부 ID 노출은 없었으나 11단계의 3월 해석과 근거 ID가 누락되어 invalid-response로 거부했다. 해당 응답을 정상 해석으로 제공하지 않는다. 두 번의 비용은 공식 표준 단가로 각각 약 $0.05759325, $0.0525219, 합계 약 $0.11011515다. 실제 청구액은 제공자 사용량 내역을 기준으로 한다.
- 전체 월 근거가 갖춰져야 한다는 기준을 완화하거나 누락된 3월 내용을 서버에서 만들어 넣지 않았다. 자동 재시도는 0회다. 추가 유료 호출은 수행하지 않았다. 같은 응답을 로컬 재생하여 오류 안내·명시적 재시도 버튼·기본 풀이 유지를 확인했다.

REQ-03·04·07·08 및 사용자가 확정한 올해 전체 유월에 맞춰 입력 안내·근거 자료·해석·툴팁을 연결했다. 입력 화면에 남아 있던 "유월 미제공" 문구를 제거했다. 격국 전체 검증이 불가능한 이유와 두 구조만 검사하는 방향은 requirements.md에 명시했다.

## 한계와 참고

179개 단위 테스트 통과는 생성 문장의 의미적 정확성을 보장하지 않는다. 실제 검증 사례는 한 명반의 응답 두 건뿐이다. 첫 응답의 모순과 두 번째 응답의 월 누락을 발견했으므로 전체 해석 품질 검증 또는 출시 준비 완료로 보고하지 않는다. 후속은 월별 생성 구조를 명시적으로 분리하는 방안과 고정 평가 사례를 검토하는 것이다. 사용자 원문을 훼손하거나 테스트를 완화하는 방식은 채택하지 않는다.
