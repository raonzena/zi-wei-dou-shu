# AI 근거 연결 개선과 Vercel 배포

- 상태: 구현·기준 사례 유년 검증·Vercel 배포 완료, 전체 의미 품질 검증 미완료
- 관련 요구사항: REQ-01·02·03·07·08, 사용자 AI 정확성 개선·AI 기본 생성·Vercel 연결 및 배포 요청

## 결정과 근거

이전 실제 응답은 대한 전택궁의 별과 유년 사화를 혼동했다. AI가 배열과 궁 ID를 직접 연결하던 입력을 서버가 계산한 명시적 위치 자료로 바꾼다. 각 운한에 본명반 궁과 운한 궁 이름, 해당 위치의 주성·사화·유요를 함께 전달한다. 계산 엔진과 화면의 사실 자료는 바꾸지 않는다. 본명반 궁과 운한 궁을 구분하고 내부 ID는 참조 필드에만 사용하도록 지침을 보완한다.

기존 gpt-5.4-mini-2026-03-17 모델을 유지하고 추론을 none에서 low로 바꾼다. 기본 출력 계약·월별 필수 필드는 유지한다. 사화가 명시된 문장을 인용한 운한의 계산값과 대조하는 회귀 검사를 추가한다. 이 검사는 모든 자연어 의미 오류를 판정하는 기능이 아니다. 원문 프롬프트는 보존하며 적용 지침은 v10이다.

## AI 기본 생성과 운영 설정

선택 체크박스·선택 영역을 제거하고 includeAi 기본값을 true로 둔다. 서버 환경변수 AI_EXPLANATION_ENABLED=false로 화면과 서버 호출을 함께 중단할 수 있다. 클라이언트가 on을 보내도 서버 플래그가 false면 외부 호출하지 않는다. 외부 전송 범위·저장 여부 안내는 입력 하단에 유지한다. 설정 반영을 위해 페이지는 동적 렌더링한다.

SDK 제한 시간은 150초, Vercel 함수 제한 시간은 180초이며 자동 재시도는 0회다. 실패 시 계산 자료와 기본 풀이를 유지한다. API 키는 Vercel production Secret에만 등록하며 클라이언트 환경변수로 제공하지 않는다. .env 파일·작업 중 응답·스킬 등 불필요한 자료는 업로드에서 제외한다.

## 검증과 요구사항 대조

`pnpm check`는 203개 테스트 통과·실호출 테스트 1개 기본 제외, 포맷·린트·타입 검사 통과다. `pnpm build`도 통과했다. AI 기본 생성은 사용자 승인에 따른 기존 선택 정책 변경이며 개인정보 안내는 삭제하지 않는다. 계산값을 AI가 재계산하지 않는 요구를 유지한다. 공유·저장과 전체 전문가 해석 검증은 이번 배포로 완료한 것으로 취급하지 않는다.

## 유년 사화 오류의 원인과 추가 보완

기준 사례의 2026년 유년 연간은 병이며 유년 화록은 천동이다. 유년 명궁은 본명반 오궁에 있고 그 궁의 천간은 경이므로, 오궁의 궁간 화록은 태양이다. v8 mini 응답은 yearly:2026과 flying:오:0을 같은 유년 문단에 인용하고 태양 화록을 올해 사화로 설명했다. 유효한 개별 ID인지 확인하는 것만으로는 서로 다른 층의 오용을 검증할 수 없었다.

v10은 서버 입력에 yearlyReadingBoundary를 두어 올해의 네 사화·연간·위치와 적용 범위를 직접 명시한다. 유년 단계의 궁간 사화 및 현재가 아닌 대한 인용을 차단하고, 유년 문장에 등장하는 사화 쌍은 올해 사화와만 대조한다. 원문에서 ‘종합’하라는 지시는 생활 주제의 연결이지 사화 표의 합산이 아님을 명시한다. 본명반 궁·운한 궁 이름을 구분하고 별의 이동처럼 서술하지 않도록 보완한다. 기존 데이터와 실제 실패를 재현하는 회귀 검사도 추가했다.

모델 상향 비교를 시도했으나 GPT-5.4 요청 2건은 HTTP 429로 생성되지 않았다. 두 번째 오류는 rate_limit_exceeded/type=tokens로 확인했다. 사용자는 모델 상향 전에 mini의 오류 원인과 프롬프트 보완을 지시했으므로 모델을 gpt-5.4-mini-2026-03-17로 유지한다. 두 요청은 GPT-5.4의 해석 품질 검증으로 집계하지 않는다.

## 보완 후 실제 mini 응답 검토

v10 실호출은 75.822초에 정상 응답했다. 입력 36,260토큰(캐시 7,936), 출력 11,205토큰을 사용했고 12개 유월·출력 계약·근거 참조 검사를 통과했다. 11단계는 천동 화록–형제궁, 천기 화권–전택궁, 문창 화과–천이궁, 염정 화기–재백궁을 계산 자료와 일치하게 설명했다. 기존의 태양 화록 혼동은 이 응답에서 재현되지 않았다. 단일 사례의 개선 확인이며 다른 명반까지 검증한 결과는 아니다.

대한 설명에는 사화가 연결되는 궁을 모호하게 묶어 쓰는 문장과 본명반·운한 궁의 구분이 빠진 표현이 남았다. ‘올해의 성패는 …에 달려 있다’는 단정적인 표현도 추가 개선 대상이다. 현재 자동 검사는 명시적인 별–사화 쌍과 참조 범위를 검사하며, 모든 궁 위치 서술과 해석 의미를 판정하지 않는다. 전체 의미 품질과 출시 수용 기준은 통과로 변경하지 않는다.

이번 작업에서 생성 응답은 mini 2건이며, 모델 비교 시도 2건은 429로 생성되지 않았다. 생성된 두 응답의 공개 토큰 단가 기준 합산 추정 비용은 약 0.15달러다. 실제 청구액은 제공자 사용량 화면을 기준으로 한다. 이후 화면·배포 검증에는 추가 유료 AI 호출을 하지 않는다.

## 배포와 화면 확인

Vercel의 sulhwadev-7966s-projects / zi-wei-dou-shu 프로젝트를 GitHub raonzena/zi-wei-dou-shu에 연결했다. CLI로 현재 작업 트리를 production에 배포했으며 배포 ID는 dpl_5jTjqargBnSyA7aFPKet12JYarqm, 상태는 READY다. 공개 주소는 https://zi-wei-dou-shu-blush.vercel.app 이다. 원격 저장소 push는 이번 CLI 배포에 필요하지 않아 수행하지 않았다.

공개 주소에서 HTTP 200, AI 기본 요청값, 선택 영역 제거, OpenAI 전송 안내를 확인했다. 로컬 production 서버에서 AI_EXPLANATION_ENABLED=false 상태로 입력부터 명반·기본 풀이까지 확인했다. 배포 환경의 유료 생성은 중복 비용을 피하려고 실행하지 않았다. 플래그를 변경한 뒤에는 Vercel에서 다시 배포해야 한다.

요구사항 대조 결과, AI 기본 생성 전환은 사용자 요청에 따른 변경이다. 계산 엔진·달력 정책·출력 필수 월과 오류 차단 기준은 유지했다. 전체 의미 품질 검증과 호출량 제한·공유 저장은 완료로 보고하지 않는다.
