# 간결한 AI 명반 해석 포맷

작성일: 2026-09-12

상태: 구현·코드 검증 완료, 실제 모델 문장 품질 추가 검토 필요

## 요청

기존 AI 프롬프트 내용을 폐기하고 사용자가 제공한 ChatGPT 공유 대화와 같은 읽기 흐름으로 결과가 나오도록 변경한다.

## 요구사항과 결정

- 기존 12단계 상담 프롬프트와 `terms`, `interpretation`, `check`, `monthly` 출력 계약을 사용하지 않는다.
- 전체 요약 다음에 핵심 성향, 일과 커리어, 돈, 관계와 배우자, 내면과 삶의 방향, 건강과 컨디션, 가족·대인관계의 일곱 분야를 고정 순서로 제공한다.
- 각 분야는 개인화된 제목과 자연스러운 1~3문단을 제공하고, 필요한 경우에만 짧은 목록을 사용한다.
- 마지막은 ‘한 줄로 정리하면’으로 시작하는 한 문단으로 마친다.
- 일반 사용자가 이해할 수 있는 차분한 존댓말을 사용하고, 전문 용어는 꼭 필요할 때만 문장 안에서 설명한다.
- 직업·재물·관계·건강을 예언하거나 숙명적으로 단정하지 않는다.
- 새 AI 해석은 본명반 근거만 사용한다. 대한·유년·유월 같은 시기 계산 자료는 상세 화면의 서버 판독 자료로 유지하되 AI 결과에는 넣지 않는다.

## 구현

- AI 응답을 `overview`, 일곱 개의 `sections`, `closing` 구조로 교체했다.
- section ID와 순서, 문단·목록 길이, 근거 ID를 서버에서 검증한다.
- 시기 근거 ID와 이전 출력 필드를 스키마에서 허용하지 않는다.
- 프롬프트에 분야별 작성 원칙, 쉬운 문장, 비단정 표현, 분야별 안전 범위를 명시했다.
- 결과 화면을 전체 요약, 일곱 분야, 한 줄 요약의 연속된 읽기 구조로 변경하고 각 블록의 근거는 접어서 확인하게 했다.
- 모의 응답과 품질 검사, 서버 요청 테스트를 새 계약에 맞췄다.
- 프롬프트 버전을 `concise-consultation-v1`로 갱신해 이전 결과 계약과 구분했다.

## 검증

- `corepack pnpm exec prettier --check`로 변경 파일 포맷을 확인했다.
- `corepack pnpm exec eslint . --max-warnings=0`을 통과했다.
- `corepack pnpm exec next typegen && corepack pnpm exec tsc --noEmit`을 통과했다.
- `corepack pnpm exec vitest run`에서 16개 파일 통과, 1개 파일 제외, 218개 테스트 통과, 1개 테스트 제외를 확인했다.
- `corepack pnpm exec next build --webpack`은 실행 환경에서 Google Fonts를 가져오지 못해 완료되지 않았다. 코드 컴파일 오류는 확인되지 않았고 CI에서 다시 검증한다.

## 남은 작업

- 운영 AI를 다시 활성화하기 전에 실제 기준 명반으로 문장 품질과 근거 충실성을 검토한다.
- 구조 검증 통과가 해석의 의미적 정확성을 보장하지 않으므로 다양한 명반 사례를 별도로 평가한다.
- 운영 호출 제한용 Supabase 연결과 전체 저장·공유 기능은 기존 후속 범위를 유지한다.
