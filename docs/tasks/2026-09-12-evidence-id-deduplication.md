- 작성일·최종 갱신일: 2026-09-12
- 상태: 완료

## 개요와 요구사항

사용자가 근거 ID 중복 때문에 응답이 차단되지 않도록 서버에서 중복 제거를 요청했다. requirements.md AI 해석의 인용 기준에 반영한다. 전체 요약·모든 분야·마무리에 적용하며 최초 순서를 유지한다.

## 결정과 근거

설치된 OpenAI SDK의 zodTextFormat은 응답 스키마를 JSON Schema로 변환한다. 외부 응답 형식은 유지하고 이미 스키마 검증을 마친 배열에 Set을 적용하는 작은 함수를 둔다. 중복 거부 함수를 교체하며 미사용 호환 경로는 남기지 않는다. 기존 min/max와 허용 ID 검사는 유지한다. 20개를 넘는 원본 목록 등 형식 오류까지 허용하는 변경은 아니다.

## 변경과 영향

validateAiExplanation의 파싱 이후 각 블록에서 중복을 제거한다. 본문은 바꾸지 않고 불명확한 근거를 추측해서 제거하지 않는다. 프롬프트·모델·API 호출 정책은 유지한다. 중복 정규화는 의미 정확성 검증을 대신하지 않는다.

## 검증

Node.js 24에서 `pnpm test:ai` 42개 통과, `pnpm typecheck` 통과. 변경 파일 Prettier와 `git diff --check` 통과. 전체 블록·순서·멱등성·원본 비변경, 알 수 없는 ID 거부와 모의 provider 응답의 정상 반환을 검사했다. 추가 유료 호출은 하지 않았다.

## 요구사항 대조와 남은 작업

요구사항과 구현을 대조했고 사용자 요청대로 중복만으로 거부하던 처리를 수정했다. 미사용 근거와 해석의 타당성은 별도의 품질 과제로 유지한다. 배포·운영 활성화는 하지 않는다.

## 후속 실제 응답 확인과 조건부 커밋

사용자가 실제 응답을 확인한 후 문제없으면 커밋하도록 요청했다. v6·동일 reference 명반으로 1회 호출했다. HTTP 200, ready, 23.077초이며 자동 구조·근거 검증과 실평가 테스트는 통과했다. 원본의 모든 블록에 중복 ID가 없었으므로 이번 호출이 중복 정규화 경로의 실증 사례는 아니다. 중복 제거는 앞선 모의 provider 테스트 및 전체 블록 테스트로 확인했다.

입력 13,945토큰(캐시 4,352), 출력 3,504토큰, 코드 단가 기준 추정 $0.023290이다. 직접 평가라 운영 Supabase 집계에는 포함되지 않는다. 원문·수동 평가는 git 제외 파일 `work/ai-evaluations/reference-1789217816650.json`에 기록했다.

수동 검토에서는 공통 설명 요구사항의 미충족이 남았다. 금전의 빠른 판단→편차→기준표 조언은 연결됐으나, 질액궁 천량·화과를 왜 장기 재정 안정장치의 근거로 사용하는지 설명이 부족하다. 다른 궁 사용 자체를 오류로 판정한 것은 아니다. 금전의 사화 ID들에는 본문에서 출발·도착 및 사용 이유를 설명하지 않은 항목이 있다. 핵심 분야의 팔좌·천요, 커리어 지겁 등 본문에서 설명하지 않은 별의 인용도 남았다. 건강의 가능성 해석은 허용 기준을 유지했다.

중복 처리 구현은 검증됐지만 전체 설명 품질은 미통과이므로 사용자의 조건에 따라 커밋하지 않는다. 추가 호출·배포·운영 활성화는 하지 않았다. 의미 설명과 미사용 근거 문제는 별도 개선이 필요하며, 이 테스트 결과를 전체 품질 통과로 간주하지 않는다.

최종 검증: `pnpm check` 통과(포맷·린트·타입·223개 테스트, 유료 평가 기본 1개 건너뜀). 종료 전 요구사항 대조에서 미충족 의미 설명을 그대로 기록했고 요구사항을 낮추지 않았다.
