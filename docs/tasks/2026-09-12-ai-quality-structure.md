# AI 출력 구조와 품질 평가 개선

- 상태: 구현 완료 / 실제 응답의 의미 품질 미통과
- 요구사항: REQ-03·04·07·08, 사용자 품질 개선 1~3번 및 서버 표시 내용·포맷 정리 요청

## 결정

기존 실패는 월별 필수 항목이 자유 문단에 섞여 있었고, 계산 사실과 제공 범위까지 AI가 재서술한 데서 확인됐다. 필수 객체 필드로 월 구간을 고정하고, 서버가 계산 자료와 표시 문구를 구성한다. 12단계 중 1단계는 서버 계산 요약, 2~12단계는 AI 해석이다. 11단계의 유월은 별도의 필수 객체에서 받아 같은 단계에 렌더링한다. 원문 프롬프트는 보존한다.

| 서버가 표시하는 내용         | 포맷                              | AI의 책임                      |
| ---------------------------- | --------------------------------- | ------------------------------ |
| 명궁·신궁, 명주·신주, 오행국 | 이름–값 목록                      | 성향과 의미 해석               |
| 엔진·달력·나이·연도 기준     | 기준 안내                         | 기준 재계산·재정의 금지        |
| 12궁·성요·밝기·생년사화      | 가로 스크롤 표 + 용어 설명        | 근거에 연결된 해석             |
| 대한·유년·유월               | 나이·연도·음력 구간, 명궁·사화 표 | 각 시기의 의미·점검 질문       |
| 궁간 사화·자화               | 출발 궁 → 도착 궁 · 별 · 사화     | 관계의 제한된 의미             |
| 격국 두 구조                 | 검사 조건 + 일치·불일치           | 조건을 바꾸거나 성패 확정 금지 |
| 제공·미제공 범위             | 고정 목록                         | 자료 존재 여부 생성 금지       |
| 근거 ID                      | 서버가 만든 사용자용 이름         | ID는 참조 필드에만 사용        |

서버 자료는 AI 미선택·실패에도 확인할 수 있다. 날짜와 근거 제목은 AI 문자열로 덮어쓰지 않는다. 순서를 가진 배열의 길이만 검사하는 방법 대신 실제 음력 구간 ID를 필수 객체 키로 사용한다. 키 집합과 내용을 검증한 뒤 서버의 시간 순서로 정렬한다. 구버전 응답 호환 분기는 만들지 않는다.

## 평가 계획

고정 계산 사례는 기존 기준 명반, 윤달, 23시, 주성 없는 명궁, 자화, 두 격국의 일치·불일치를 포함한다. 자동 검사는 계약·근거·누락·중복·관찰한 모순과 내부 ID 노출을 다룬다. 의미 평가 기준은 자료 충실도, 모순, 시기별 구체성, 반복, 한국어 가독성, 과도한 단정이며 별도 평가 문서에 기록한다. 소수 실호출을 명시적으로 선택할 수 있는 평가 도구를 만들고 기본 검사는 외부 호출 없이 실행한다.

## 검증·요구사항 대조

기존 모델·추론 설정·자동 재시도 0회·개인정보 제외 정책을 유지했다. 사용자 원문 프롬프트를 보존하고 서비스용 출력 계약만 변경했다. REQ-03·04의 계산 자료·해석 표시, REQ-07의 용어 설명, REQ-08의 사실에 연결된 해석 요구를 대조했다. 월 누락과 의미 오류의 허용 기준을 완화하지 않았다. 구조 개선은 완료했지만 정확한 AI 해석의 수용 기준은 아직 충족하지 못했다.

- 최종 `pnpm check`: 포맷·lint·타입 검사 통과, 테스트 197개 통과·유료 검사 1개 기본 건너뜀. `pnpm build` 통과. 사용자 원문 프롬프트가 이전 커밋과 동일함을 대조했다.
- 고정 사례 6개: 기준 명반, 윤달, 늦은 자시, 주성 없는 명궁, 자부동궁, 자부협명. 윤달 전·후반 필수 필드, 월 누락·위조·공백·순서, 참조 검사, AI 오류 시 계산 자료 유지 등을 외부 호출 없이 검사한다.
- 브라우저: AI 미선택 상태의 계산 자료와 모의 응답의 2~12단계·12개월 표시를 확인했다.
- 실호출은 기준 사례 1회만 수행했다. HTTP 200, 68.6초, 입력 22,193·출력 9,808토큰, 캐시 0, 추정 비용 $0.06078075였다. 실제 API 통합 검사는 응답이 거부되어 실패했다.
- 저장된 응답을 추가 호출 없이 재평가했다. 스키마 통과, 월별 필드 12/12, 본문·참조 검사 실패로 분리 기록했다. 최초 평가기의 월 개수 0 표시는 실패 종류를 합친 집계 오류였으며 평가기를 수정하고 회귀 검사를 추가했다.
- 내용 대조: 10단계가 전택궁의 천기·태음을 자미·태음으로 설명하고 대한 사화를 혼동했다. 11단계는 올해 천동 화록을 태양 화록으로, 염정 화기의 재백궁을 질액궁으로 잘못 설명했다. 내부 ID도 문장에 노출됐다. 자동 검사는 내부 ID를 차단했지만 이런 의미 오류 전체를 탐지한다고 보장하지 않는다.
- 평가 원문은 git에서 제외한 work/ai-evaluations에 권한 0600으로 저장한다. 원본 입력·요청 헤더·키는 기록하지 않는다. 이번 내용 대조는 개발 중 보조 검토이며 자미두수 전문가 검토를 대체하지 않는다.

## 남은 문제와 개선 조건

실제 해석의 자료 충실도·일관성은 미통과다. 계산 사실을 AI가 문장으로 다시 언급할 때 층위를 혼동하는 문제가 남아 있다. 후속 작업에서는 평가 사례에 대한 의미 검토와 근거 연결 방식을 보완해야 한다. 모델·추론 설정 비교는 별도 승인 범위이며 이번에는 변경하지 않았다. 다양한 사례의 실호출, 전문가 검토, 전체 출시 검증은 수행하지 않았다. 공유·저장 등 기존 미구현 범위도 유지한다.
