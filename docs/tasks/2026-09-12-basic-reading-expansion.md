# 기본 풀이 원문 대조·내용 확장·질문 제거

- 상태: 구현·검증 완료
- 관련 요구사항: REQ-03·04·05·07, 사용자 기본 풀이 확장·질문 제거·제목 형식 변경 요청

## 결정과 구현

iztro 14주성 문서의 각 별 특성 절을 읽고, 앞서 일부 특징만 다뤘던 설명을 성향·강점·주의점의 세 문단으로 보충했다. 기존 fluent-korean 지침에 따라 문장의 주체와 의미를 명확히 쓰고 어려운 비유와 용어 나열을 피했다. 제목은 ‘~하는 사람’으로 바꾸고 성격을 확정하지 않는다는 공통 안내를 둔다.

기본 풀이의 question과 화면의 ‘나에게 물어보기’를 제거했다. meaning은 문자열로 유지하고 빈 줄을 문단 경계로 렌더링한다. 규칙 버전은 ming-major-v3다. AI 해석의 check는 별도 기능이므로 유지하며, AI에서도 쓰는 question 스타일은 삭제하지 않는다. 원문 출처와 작성자, MIT 고지를 THIRD_PARTY_NOTICES.md에 기록했다.

## 원문 대조 기준

- 자미·천기·태양·무곡: 시야와 인정 욕구, 기획과 실행의 균형, 표현과 관계의 경계, 독립적 실행과 조언 수용을 보충했다.
- 천동·염정·천부·태음: 안정과 거절, 진지함과 자기 보호, 실속과 만족, 감수성과 주변 환경의 영향을 보충했다.
- 탐랑·거문·천상·천량: 관심과 몰입, 정보·표현과 속마음, 조직과 문제 해결, 소신과 보호를 보충했다.
- 칠살·파군: 끈기와 사전 검토, 변화의 구상·실행과 대안을 보충했다.

거문의 화권·화기, 천상의 밝기, 다른 별의 조합 절을 조건 없는 단일 별 설명으로 옮기지 않았다. 성별·외모·인격을 단정하는 표현이나 가족의 실제 행동을 추정하는 문장은 채택하지 않았다. 생활 속 예시와 실천 제안은 원문 주제를 풀어 쓴 편집 문장이며, 특정 사건이나 성공을 예측하지 않는다. 원문 전체의 번역이나 전문가가 검증한 종합 풀이로 표시하지 않는다.

## 요구사항 대조와 검증

질문 삭제는 사용자가 승인한 요구 변경이며 requirements.md와 ADR·화면 흐름을 함께 갱신했다. 기존 근거·출처·툴팁, 별 없음·복수 별 구분, 조합 미해석 범위를 유지한다. 테스트의 폐기된 질문 검사를 제거된 필드 확인으로 갱신한다. 외부 AI 호출은 하지 않는다.

검증 결과: `pnpm check`의 포맷·lint·타입 검사와 테스트 197개가 통과했으며, 유료 검사 1개는 기본 설정대로 건너뛰었다. `pnpm build`와 `git diff --check`가 통과했다. 실제 브라우저에서 기존 기준 사례를 AI 미선택으로 계산해 두 별의 제목·세 문단 표시와 질문 영역 제거를 확인했다. 기본 풀이 데이터·전달 타입·화면에 question 참조가 남지 않았음을 검색으로 확인했다.

## 남은 범위

별의 조합·사화·밝기까지 적용한 규칙 기반 풀이와 전문가 내용 검토는 별도 후속 작업이다. AI 의미 품질 미통과 상태는 이번 작업으로 해결된 것이 아니다.
