# 첫 화면의 자미두수 소개

- 작성일: 2026-09-14
- 최종 갱신일: 2026-09-14
- 상태: 구현·로컬 검증 완료

## 작업 개요

출생 정보만 바로 요구하던 첫 화면에 자미두수의 기본 구조와 사주와의 차이를 설명한다. 자미두수를 처음 접하는 사용자가 자신의 명반에 놓인 별을 궁금해하며 자연스럽게 입력으로 이어지게 하는 것이 목적이다.

## 요구사항

- REQ-01, REQ-08과 연결한다.
- 입력 폼보다 먼저 자미두수가 무엇인지 쉬운 말로 설명한다.
- 사주와의 차이는 해석 체계의 차이로 설명하고 정확도의 우열을 주장하지 않는다.
- 작은 화면에서도 소개를 먼저 읽은 뒤 입력 폼으로 이어지게 한다.

## 결정과 근거

iztro 2.6.1의 공식 README와 학습 문서를 기준으로 자미두수를 출생 날짜·시각을 바탕으로 만든 열두 궁의 명반에서 별의 배치와 관계를 읽는 체계로 설명했다. 사주는 연주·월주·일주·시주의 여덟 글자를 구성하는 체계라는 한국민족문화대백과사전의 설명을 참고했다. 두 체계의 우열이나 적중률은 근거 없이 비교하지 않는다.

긴 이론 설명이나 전문용어 목록 대신 `자미두수란 무엇인가요?`, `사주와는 무엇이 다른가요?`라는 두 질문으로 나눴다. 데스크톱에서는 폼 왼쪽에, 작은 화면에서는 폼 위에 표시해 기존 입력 흐름을 유지한다.

## 변경 내용과 영향

- 첫 화면의 소개 영역에 자미두수의 열두 궁·별 조합과 사주의 네 기둥·여덟 글자·오행 중심 접근을 설명했다.
- 소개 끝에 사용자의 명반에 어떤 별이 놓였는지 묻는 문장으로 입력 행동을 연결했다.
- 정적 소개를 기존 입력 컴포넌트 안에 배치했으며 계산·저장·AI 동작은 바꾸지 않았다.

## 검증

- `corepack pnpm format:check` 통과
- `corepack pnpm lint` 통과
- `corepack pnpm typecheck` 통과
- `corepack pnpm build` 통과

안내 문구의 문자열을 그대로 복제하는 테스트는 정적 선언 테스트가 되어 변경 가치를 검증하지 못하므로 추가하지 않았다. 소개 영역은 계산·저장·AI 동작에 영향을 주지 않는다.

## 요구사항 대조

REQ-01의 첫 화면 안내와 REQ-08의 일반 사용자 대상 쉬운 설명을 반영했다. 계산 방식과 결과 구조는 변경하지 않았다.

## 남은 문제와 추후 개선점

배포 미리보기에서 모바일과 데스크톱의 줄바꿈 및 입력 폼과의 균형을 최종 확인한다.
