# 성향 캐릭터와 결과 공유 이미지

- 작성일: 2026-09-18
- 최종 갱신일: 2026-09-18
- 상태: 구현 완료, 운영 공유 미리보기 확인 대기

## 작업 개요

종합적인 나의 성향에 주성별 캐릭터를 표시한다. 사용자가 선택한 성별에 맞는 이미지를 제공하며 공유 미리보기에도 동일한 캐릭터를 사용한다.

## 요구사항

REQ-03/05, REQ-06에 표시·보관 기준을 반영한다. 사용자가 주성별 캐릭터와 두 주성의 병렬 표시를 선택했다. 이미지는 개별 제작하고 글자를 포함하지 않으며 궁 이름은 텍스트로 표시한다. 관련 없는 테스트는 실행하지 않는다.

## 결정과 근거

기존 `createBasicReading`의 entries를 사용해 실제 풀이와 동일한 주성을 선택한다. 별도 성향 점수나 임의의 대표 주성을 만들지 않는다. 무주성은 기존 대궁 참고 로직을 유지한다. 성별을 저장하지 않던 기존 결과에서는 이미지 성별을 추정하지 않는다. 새 결과는 characterGender를 보관하고 중복 판별에 반영한다.

12궁 시안을 화풍 참고로 사용해 14주성 캐릭터를 개별 생성하고 성별 변형을 제작한다. 캐릭터는 별의 특징을 표현하는 창작 삽화이며 전통적인 신상이나 사용자 외모 예측이 아니다. 사용자별 이미지 생성은 수행하지 않는다. 사용자 피드백에 따라 여성 캐릭터의 얼굴과 의상을 다시 제작하고, 상체가 평평하게 표현된 부분은 가슴·허리 윤곽과 옷 주름을 자연스럽게 수정했다. 성인 캐릭터의 활동과 소품, 기존 중국풍 화풍을 유지한다.

Next.js 로컬 공식 문서의 next/image와 ImageResponse 방식을 사용한다. 오픈그래프는 로컬 이미지 합성만 수행하고 결과 조회와 동일한 만료 검사를 거친다. 개인정보 안내의 성별 미저장 문구는 이번 사용자 요청에 맞게 수정한다.

## 변경 내용과 영향

정적 캐릭터 이미지, 성향 표시 컴포넌트, 결과 스냅샷과 저장 액션, fingerprint, 결과 메타데이터와 이미지 응답 경로를 수정한다. 이미지 원본은 생성 도구의 기본 보관 위치에 유지한다. DB 스키마는 변경하지 않는다.

## 검증

관련 테스트 9개 파일의 29개 테스트가 통과했다. 주성 선택·성별·무주성·저장 복원·공유 메타데이터·이미지 응답을 검증하며 실제 ImageResponse의 PNG 생성과 1200×630 크기도 확인했다. 타입 검사와 변경 코드의 ESLint 검사가 통과했다. 최종 여성 이미지 14장을 교체한 후 파일 매핑·실제 PNG 생성에 해당하는 2개 파일의 5개 테스트를 다시 실행해 통과했다. 전체 테스트와 AI 해석 유료 호출은 수행하지 않았다.

프로덕션 빌드는 최초 Google Fonts 호스트 조회 실패(ENOTFOUND)로 중단됐지만, 네트워크 권한을 받은 뒤 다시 실행해 통과했다. 공유 이미지 라우트의 빌드 추적 파일에 캐릭터 28장이 모두 포함된 것을 확인했다. 로컬 개발 서버는 포트 바인딩 권한 오류(EPERM)로 실행하지 못해 브라우저 화면 확인은 미검증이다. 임시 화면 확인용 페이지는 제거했다.

## 요구사항 대조

성별별 캐릭터와 공개 미리보기 요구를 기준 문서와 개인정보 안내에 반영했다. 기존의 성별 미저장 기준은 이미지 복원을 위해 변경했다. 생년월일·출생 시각은 계속 저장하지 않는다.

## 남은 문제와 추후 개선점

운영 배포 이후 외부 공유 서비스의 실제 미리보기와 캐시 갱신을 확인해야 한다. 기존 결과는 성별 정보가 없어 성별별 캐릭터를 제공하지 않는다.
