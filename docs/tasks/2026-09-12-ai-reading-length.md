# AI 해석 본문 분량 조정

- 작성일·최종 갱신일: 2026-09-12
- 상태: 프롬프트 수정·모의 검증 완료. 실제 생성·배포는 미실행.

## 작업 개요와 요구사항

사용자는 AI 해석이 짧은 이유를 확인하고 각 섹션을 4~5문장으로 작성하도록 요청했다. Supabase 호출 제어의 동작도 설명한다. 관련 요구사항은 REQ-03의 해석과 운영 기준이며, AI 중지 결정은 유지한다.

## 확인한 원인과 결정

기존 최종 프롬프트에는 단계별 핵심 1~~2개에 집중하고 월별 해석을 2~~3문장으로 간결하게 쓰라는 지침이 있었다. 화면은 interpretation 전체를 렌더링하며 문장을 잘라 요약하지 않는다. 스키마의 길이 제한은 초과 응답을 거절하는 용도이며 내용을 잘라내지 않는다.

각 단계의 interpretation 전체를 합쳐 4~~5문장으로, 각 월별 구간의 interpretation도 각각 4~~5문장으로 요청한다. 용어 풀이와 실천 조언은 본문 문장 수에서 제외한다. 여러 문단으로 나누더라도 문단마다 분량을 반복하지 않는다. 첫 단계의 명반 판독 요약은 서버가 표시하는 사실 정보이므로 AI 분량 규칙을 적용하지 않는다.

핵심 흐름, 계산 근거의 의미, 일상적인 예시, 주의점이나 균형을 설명하도록 한다. 분량을 채우기 위한 반복과 근거 없는 사실 생성은 금지한다. 근거가 부족하면 설명 가능한 범위와 한계를 밝힌다. 모델·출력 토큰 한도·스키마는 변경하지 않는다.

## 변경 내용과 영향

`consultation-prompt.ts`의 축약 지침을 교체하고 `explain.server.ts`의 프롬프트 버전을 v11로 올렸다. 기존 호출 제어의 중복 식별에도 새 버전이 반영된다. 프롬프트로 분량을 요청하며 문장 수를 세어 응답을 거절하거나 자동 재호출하지 않는다. 실제 모델의 준수 여부는 별도 확인이 필요하다.

Supabase 호출 제어는 [운영 제어 작업 기록](2026-09-12-ai-usage-controls.md)의 예약 → AI 생성 → 정산 흐름을 따른다. 서버가 RPC로 중복·횟수·예산을 함께 검사하고 허용된 경우에만 OpenAI를 호출한다. 원격 Supabase 연결은 아직 대기 중이다.

## 검증

`pnpm test:ai`의 모의 AI 요청·해석 검증 47개가 통과했다. 변경 파일의 포맷 경고를 수정했고 `git diff --check`도 통과했다. 실제 AI 호출은 하지 않았으며 운영의 비활성 플래그를 유지한다. 이 검사는 모델의 실제 문장 수 준수 여부를 검증한 결과가 아니다.

## 요구사항 대조와 남은 작업

쉬운 한국어, 근거 연결, 계산 자료의 정확성 지침을 유지하면서 사용자 요청대로 본문 분량을 구체화했다. 요구사항을 축소한 항목은 없다. 실제 4~5문장 준수 여부와 출력 길이·지연의 영향은 다음 유료 품질 평가 시 확인한다. Supabase 운영 연결과 배포는 이번 프롬프트 수정으로 완료 처리하지 않는다.
