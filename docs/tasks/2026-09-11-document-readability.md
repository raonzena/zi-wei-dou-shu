# 기존 문서의 한국어 가독성 개선

- 작성일: 2026-09-11
- 최종 갱신일: 2026-09-11
- 상태: 완료

## 작업 개요

사용자 요청에 따라 기존 Markdown 문서 19개를 fluent-korean 지침에 맞춰 다듬었다. 요구사항과 기술적 의미를 유지하면서 압축된 표현을 풀어 쓰고, 긴 설명을 읽기 쉬운 단락으로 나누는 작업이다.

대상은 루트 README와 AGENTS.md, 요구사항, 화면 흐름, 기술 선택 기록, 작업별 기술 문서와 작성 템플릿이다. 이번 작업의 기록은 별도 페이지로 추가한다.

## 요구사항

사용자는 기존 문서에 fluent-korean 지침을 적용하도록 요청했다. 문장의 주어와 조건, 동작을 명확히 표현하되 REQ-01~10의 범위와 수용 기준을 유지해야 한다. 기존 계산 정책과 사용자 결정, 검증 결과, 미구현 범위도 보존한다.

[요구사항 9절](../requirements.md#9-작업-종료-전-점검과-변경-기록)에 따라 작업 종료 전에 요구사항과 변경 내용을 대조한다. 작업별 문서 작성 규칙에 따라 이 페이지와 작업 목록을 갱신한다.

## 결정과 근거

- 전역 AGENTS.md에 추가한 fluent-korean 지침과 기존 문서를 읽고 수정했다. 명사만 나열한 문장은 동작과 조건이 드러나도록 풀어 쓰고, 여러 주제가 이어지는 단락은 나눴다.
- 문서의 기존 서술체인 ‘한다’를 유지했다. 널리 사용하는 기술 용어와 API 이름은 불필요하게 번역하지 않았다.
- 과거 조사에서 기록한 보류 상태를 삭제하지 않았다. 후속 결정이 있는 문서에는 당시 기록이라는 안내와 후속 문서 링크를 추가했다. 작업 목록은 이미 기록된 최종 결정을 반영해 현재 상태를 요약했다.
- 코드 블록, 설정값, 계산 예제와 출처 링크는 보존한다. Next.js가 관리하는 영문 규칙도 수정하지 않는다.
- 새로운 기술 조사나 제품 정책 결정은 진행하지 않았다. 문서에 남아 있는 과거 테스트 수와 검증 결과는 해당 작업 당시의 기록이며 이번에 다시 실행한 결과가 아니다.

## 변경 내용과 영향

README는 서비스의 목표와 현재 구현 범위를 구분해 설명한다. 요구사항 문서는 확정 요구사항을 완성된 문장으로 표현하고, 과거 변경 기록과 현재 결정을 구분해 읽을 수 있도록 안내한다.

화면 흐름과 ADR은 상태 설명, 데이터 처리 과정, 정책의 적용 조건을 풀어 썼다. 작업 문서는 변경 내용과 검증 한계가 드러나도록 문장을 다듬었다. AGENTS.md와 템플릿도 문서 작성 지시가 명확하게 읽히도록 정리했다.

앱 코드, 패키지, 계산 규칙과 화면 동작은 변경하지 않는다.

## 검증

`pnpm format:check`와 `git diff --check`가 통과했다. 기존 문서 19개의 코드 블록, 인라인 코드, 제목, 기존 링크와 숫자값이 보존됐는지 검사했다. 변경한 문서의 상대 링크가 가리키는 파일과 문서 내부 제목도 확인했다.

변경 내역을 검토해 수정 범위가 Markdown 문서로 한정된 것을 확인했다. 문서 검토 중 README의 본문이 앞선 목록에 이어지거나 새 작업 행이 표에서 분리되는 문제를 발견해 수정했다.

문서만 수정하므로 앱 테스트와 운영 빌드는 다시 실행하지 않는다. 과거 조사 자료의 사실관계나 계산 정확성을 새로 검증하는 작업도 이번 범위에 포함하지 않는다.

## 요구사항 대조

REQ-01~10과 화면별 수용 기준, 계산 및 해석 품질 기준을 수정 전후로 대조했으며 의미가 달라진 항목은 없었다. 지원 연도와 날짜·시각 입력 범위, 한국 음력 변환, 역사적 시간 보정, iztro의 윤달·자시 처리에 대한 기존 결정을 유지한다.

문서의 표현을 수정하는 작업이므로 요구사항 수행 불가에 따른 방향 변경은 없다. 개인화 해석, 상세 화면, 공유, 용어 설명과 추가 독립 검증은 기존의 후속 작업으로 남긴다.

## 남은 문제와 추후 개선점

후속 작업에서 상태가 바뀌면 개별 문서의 기록 시점과 작업 목록의 현재 상태를 함께 갱신한다. 새 문서도 같은 작성 기준을 따른다. 별도의 문서 도구나 자동화 패키지가 필요한 상황은 확인하지 않았다.
