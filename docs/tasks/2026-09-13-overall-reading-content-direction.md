# 종합 풀이 콘텐츠 구조 개편

- 작성일: 2026-09-13
- 최종 갱신일: 2026-09-13
- 상태: 구현·코드 검증 완료

## 작업 개요

종합 풀이를 ‘종합적인 나의 성향’과 일곱 생활 분야로 다시 구성한다. 전체 성향은 어떤 명식인지, 강점, 아쉬운 점과 보완 방향을 4~5문장으로 요약한다. 분야별 본문은 별의 공통 문장을 반복하지 않고 해당 궁의 생활 주제에 맞게 설명한다.

## 요구사항

- REQ-03 / REQ-05: 종합 풀이의 제목, 요약 분량과 일곱 분야의 순서를 변경한다.
- 해석 정책과 품질: iztro 2.6.1의 계산 결과와 공식 14주성·동궁 조합 원문을 우선 근거로 사용한다.
- 사용자 추가 지시: 건강과 컨디션에는 업무 방식이 아닌 피로·수면·휴식·생활 리듬의 내용을 제공한다.

## 결정과 근거

- 설치된 iztro 2.6.1은 주성 배치와 무주성 명궁의 대궁 참조를 제공하지만, 패키지 내부에 사용자용 해석 문장은 포함하지 않는다.
- 명반 배치와 대궁은 설치된 iztro 계산 결과를 사용하고, 기본 성향과 두 주성 조합은 프로젝트가 출처로 관리하는 iztro 공식 14주성 원문을 반영한다.
- 같은 별의 공통 문장을 모든 분야에 복사하면 건강에 업무 방식이 나타나는 문제가 생긴다. 별의 핵심 태도만 가져오고, 궁별 강점·주의점·생활 장면은 별도의 문장으로 구성한다.
- AI가 활성화될 때에도 화면의 분야 순서와 명칭이 달라지지 않도록 응답 계약과 프롬프트를 함께 변경한다.

## 변경 내용과 영향

- 규칙 기반 기본 풀이의 제목을 ‘나를 알아보는 풀이 / 종합적인 나의 성향’으로 바꾸고, 단일 주성·두 주성·무주성 명식의 요약을 4~5문장으로 구성했다.
- 분야별 풀이를 핵심 성향, 내면과 삶의 방향, 일과 커리어, 재물운, 연애 및 결혼운, 건강과 컨디션, 가족과 대인관계 순서로 변경했다.
- 열두 궁마다 주성의 핵심 태도, 해당 생활 분야의 강점과 아쉬운 점, 구체적인 생활 장면을 네 문장으로 제공한다.
- 질액궁은 14주성의 특징을 피로·수면·휴식·활동 리듬에 맞춰 별도로 연결한다. 업무 절차나 직업 관련 예시는 관록궁에만 표시한다.
- AI 결과의 일곱 분야 순서와 명칭, 전체 요약 프롬프트와 품질 검사를 같은 기준으로 변경했다.
- 기존 결과의 저장 계약은 변경하지 않았다. 저장된 명반과 기본 풀이 근거를 현재 배포의 문장 템플릿으로 표시하므로 이전 결과도 새 화면 문구를 사용한다.

## 요구사항 대조

- REQ-03 / REQ-05의 요약 분량, 일곱 분야 명칭과 순서를 코드·프롬프트·화면 흐름에 동일하게 반영했다.
- 두 주성은 하나만 선택하지 않고 iztro 원문에서 확인한 24개 실제 동궁 조합을 사용한다.
- 무주성 궁의 대궁 참조와 열두 궁 구분을 유지했다.
- 건강과 컨디션 본문에는 피로·수면·휴식·생활 리듬만 표시하며 업무·마감 문장이 섞이지 않는 테스트를 통과했다.
- `예를 들어`, `이 영역에서는`, `살펴봅니다`, `해보세요`가 분야별 본문에 반복되지 않는 테스트를 통과했다.
