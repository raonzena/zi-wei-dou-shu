# 전역 지침을 저장소에 포함

- 작성일: 2026-09-13
- 상태: 반영 완료

## 작업 개요와 요구사항

사용자 요청으로 전역 AGENTS.md에 있는 지침을 저장소의 AGENTS.md에 포함한다. 다른 환경에서도 저장소만으로 한국어 작성 규칙을 읽을 수 있게 한다. 제품 기능 요구사항은 변경하지 않는다.

## 확인과 결정

전역 파일에는 일반 작업·답변 원칙과 fluent-korean 지침 전문·MIT 라이선스가 있었다. 별도 스킬 파일을 참조하는 목록은 없었다. 따라서 fluent-korean 전문을 축약하지 않고 복사했으며 출처와 저작권·라이선스도 보존했다. 일반 원칙은 기존 프로젝트 규칙과 대조하고 빠져 있던 라이브러리 선택·장기 아키텍처·사용자 숙련도 관련 내용을 반영했다. 기존 요구사항 대조·기술 문서·커밋·Next.js 규칙은 유지한다.

## 변경과 영향

저장소 AGENTS.md는 로컬 전역 파일 경로에 의존하지 않는다. 본문을 그대로 보존하기 위해 해당 영역만 Prettier 무시 주석으로 감쌌다. 도구에서 제공되는 전체 스킬 목록이나 설치된 플러그인까지 복사하는 작업은 아니다. 다른 AI 도구에서도 AGENTS.md를 읽도록 지원하거나 설정해야 한다.

## 검증과 요구사항 대조

fluent-korean 전문과 라이선스가 전역 원본과 동일한지 비교해 일치함을 확인했고, 기존 Next.js 지침 보존과 포맷·diff 검사도 통과했다. 문서 작업이므로 앱 빌드와 기능 테스트는 수행하지 않는다. 현재 requirements.md의 쉬운 설명·직접적인 한국어 문체와 충돌하지 않으며 제품 동작은 바뀌지 않는다.

## 남은 사항

다른 컴퓨터에서 실제 에이전트가 지침을 읽는 검증은 수행하지 않았다. GitHub를 통한 전달에는 커밋·푸시가 필요하다.

원격 main에 새 기능 커밋 2개가 있어 최초 푸시가 거절됐다. 원격 변경 위로 리베이스하고 작업 목록의 추가 행 충돌은 양쪽 기록을 모두 보존해 해결했다. 앱 코드는 변경하지 않았다.
