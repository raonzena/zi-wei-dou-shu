- 작성일: 2026-09-13
- 상태: 구현 완료

## 작업 개요와 요구사항

사용자가 이미지로 지정한 설명 종류·버전, 출처 링크, 라이선스 영역의 글자와 여백을 줄인다. REQ-04·07의 출처 표시를 유지한다.

## 결정과 변경

기존 근거 안내에 사용하는 10px 크기로 세 줄을 통일한다. 줄 높이 1.5, 줄 간격 4px, 위 여백 8px을 사용하고 문단의 기본 마진을 제거한다. 전용 스타일로 별 설명 본문과 다른 안내에는 영향을 주지 않는다. 출처 링크와 라이선스 내용은 유지한다.

## 검증

포맷·타입 검사와 기존 궁 표시 테스트 5개, git diff --check를 통과했다. 단순 스타일 변경을 복제하는 새 테스트는 추가하지 않는다. 실제 브라우저 시각 검증은 수행하지 않았다.

## 요구사항 대조와 남은 사항

출처·버전·라이선스를 계속 표시하며 본문 내용·계산·DB는 변경하지 않는다. 요구사항과의 충돌이나 미결정 사항은 없다.
