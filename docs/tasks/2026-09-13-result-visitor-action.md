# 결과 방문자에 따른 버튼 문구

- 작성일: 2026-09-13
- 상태: 완료

## 작업 개요와 요구사항

공유 링크 방문자와 결과 생성자에게 맞는 하단 버튼 문구를 제공한다. 사용자가 요청한 플래그 또는 별도 URL 방식 중 기존 서버의 isOwner 판정을 사용한다.

## 결정과 근거

loadResult는 생성 브라우저의 HttpOnly 쿠키와 저장된 소유 해시를 비교해 isOwner를 반환한다. 이를 재사용하므로 새 URL이나 설정을 추가하지 않는다. 이는 링크가 실제로 공유되었는지 추적하는 값이 아니라 생성 브라우저인지 구분하는 값이다. 쿠키를 지우거나 다른 브라우저를 사용하면 방문자로 표시한다.

## 변경 내용과 영향

생성 브라우저는 ‘명반 다시 보기’, 그 외 방문자는 ‘나도 확인해보기’를 표시한다. ChartResult에는 버튼 문구를 전달한다. 두 버튼 모두 `/`의 새 입력으로 이동하며 기존 결과를 재계산하지 않는다. AI 재시도 권한과 공개 결과 경로는 유지한다.

## 검증

타입 검사, 저장·소유권 관련 기존 테스트 6개와 git diff --check를 통과했다. 표시 문구 분기만 추가했으므로 새 테스트는 작성하지 않았다. 브라우저 시각 검증과 AI 호출은 수행하지 않았다.

## 요구사항 대조

버튼 위치·구분선은 유지하고 요구사항과 화면 흐름에 문구 분기와 이동 목적지를 기록했다. 원본 출생 정보는 저장하지 않으므로 기존 입력을 편집하는 동작으로 설명하지 않는다.

## 남은 문제와 추후 개선점

소유 쿠키가 없으면 생성자와 방문자를 구분할 수 없다. 이는 현재 비회원 소유권 정책에 따른 동작이다.
