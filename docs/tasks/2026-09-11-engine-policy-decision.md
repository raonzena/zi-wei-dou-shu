# 초기 엔진과 계산 정책 결정

- 작성일: 2026-09-11
- 최종 갱신일: 2026-09-11
- 상태: 문서화 완료 / 엔진·시간 처리 구현과 독립 검증 미완료

## 작업 개요

초기 iztro 사용과 후속 TypeScript 자체 구현 결정을 반영하고, 초기 계산 정책 ziwei-v1을 명세했다. 실행 코드나 패키지 변경은 이번 범위에 없다.

## 요구사항

REQ-01·09·10, 계산 품질 기준, OPEN-01·02·03에 해당한다. 사용자는 초기 iztro 사용과 추후 필요한 기능의 직접 구현을 지정했으며, 추가 응답으로 1900년 이후 대한민국 출생·역사적 시간 보정을 선택했다.

## 결정과 근거

[ADR-0003](../decisions/0003-engine-and-calculation-policy.md)을 현재 정책 원본으로 작성했다. 한국 음력 입력은 실제 양력 생일로 변환해 iztro 내장 달력으로 배치한다. yearDivide normal, dayDivide forward, fixLeap true, algorithm default와 엔진 기본 사화·밝기 표를 초기 구현 기준으로 선정했다. 이는 사용자 개별 지정이 아닌 이번 기술 결정임을 구분했다.

시간 처리는 역사적 Asia/Seoul로 입력 시각을 해석한 뒤 같은 순간을 고정 UTC+09:00 계산 시각으로 정규화하는 기준을 명시했다. 진태양시 보정은 적용하지 않는다. 존재하지 않거나 중복되는 시각은 임의 보정하지 않는다. 선택한 역사적 시간 보정 범위와 이를 구현하는 구체적 기준을 ADR에서 구분했다.

설정의 의미는 공식 iztro 문서와 설치 소스, 과거 표준시·DST 존재는 IANA tz 자료를 확인했다. 미래 엔진을 위해 현재 다중 엔진 레지스트리나 호환 레이어를 만들지 않는다.

## 변경 내용과 영향

새 ADR, 요구사항, 화면 흐름, README, 이전 조사 문서와 작업 목록을 갱신했다. 기존 평가의 채택 보류를 새 결정으로 대체하고 이전 기록은 당시 검토 상태임을 명시했다. 전체 계산 정확성 검증 완료나 초기 입력 UI 구현 완료로 처리하지 않았다.

## 검증

공식 설정 정의와 설치된 iztro의 fixLunarMonthIndex를 확인했다. 늦은 자시(timeIndex 12) 윤달 처리 예외를 발견해 필수 경계 검증에 포함했다. 문서 포맷·상대 링크·git diff --check를 확인한다. 실행 코드 변경이 없어 앱 테스트·빌드는 재실행하지 않는다. 독립 명반·역사적 시간 변환 검증은 아직 수행하지 않았다.

## 요구사항 대조

초기 엔진 선택은 사용자 지시이며 REQ-01~10을 유지한다. 지원 연도·시간 정책은 사용자 응답으로 구체화했다. 시각 미상은 기존 임의 계산 금지 기준에 따라 제출을 차단한다. 기능 수행 불가로 요구사항을 축소한 변경은 없다. 추후 자체 구현의 한국 음력 배치 규칙은 아직 별도 결정이 필요하다.

## 남은 문제와 추후 개선점

다음 작업은 정책에 따른 날짜·시간 입력 검증과 정규화 구현이다. 채택 라이브러리의 지원 경계와 역사적 시간 자료를 확인하고 1900년부터의 지원을 검증해야 한다. 이어 윤달·자시·연도 경계 및 독립 명반 검증 후 실제 명반 흐름을 연결한다. 자체 구현은 필요한 본명반 기능부터 개발하고 별도 정책으로 검증한 후 새 생성 경로를 교체한다.
