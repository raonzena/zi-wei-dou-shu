# 규칙 기반 기본 풀이 설계와 첫 연결

- 작성일: 2026-09-11
- 상태: 명궁 주성 기본 풀이 구현 완료 / 종합·주제별 풀이와 AI 설명은 후속 작업

## 작업 개요

디자인을 `7594aae feat/chinese-visual-design`으로 커밋한 뒤 개인화 해석 설계를 시작했다. 규칙 기반과 AI 방식의 장단점을 설명했고, 사용자가 규칙 기반부터 시작해 이후 AI 설명을 추가하는 방향을 승인했다. 이전의 생성 방식 선택 대기는 해소했다.

## 요구사항

REQ-03·05·07과 계산·해석 품질 기준, OPEN-05를 따른다. 명반 아래에 풀이와 근거를 표시하고 탭 전환 시 같은 결과를 사용한다. 전체 개인화 해석의 첫 구현으로 명궁 주성을 다루며, 전체 출시 수용 기준 완료를 뜻하지 않는다.

## 결정과 근거

규칙 기반은 같은 입력과 버전에서 결과가 일정하고 근거 추적이 쉽지만 콘텐츠 검토가 필요하다. AI는 유연한 설명에 유리하지만 생성 오류·비용·외부 처리와 근거 이탈 평가가 추가된다. [ADR-0004](../decisions/0004-rule-based-interpretation.md)에 단계적 도입 결정을 기록했다.

iztro의 기존 궁·14주성 설명과 코드의 용어집을 확인했다. 각 주성의 일반적 의미를 짧은 한국어 문장으로 요약하고, 원문을 길게 번역하거나 복제하지 않았다. ‘나에게 물어보기’는 서비스가 작성한 질문이며 예측이나 출처의 판단으로 표시하지 않는다. 이 출처 대조는 독립 전문가의 해석 품질 검증과 다르다.

## 변경 내용과 영향

- `src/content/basic-reading-rules.ts`: 주성별 의미·질문·규칙 ID와 버전, 공통 출처를 관리한다.
- `src/domain/interpretation/basic-reading.ts`: 검증된 Chart에서 명궁과 주성만 선택한다. 근거 위치·별·규칙 ID를 포함한 결과를 만들며 명반을 다시 계산하지 않는다.
- `src/features/interpretation/`: 근거, 별의 기본 의미, 질문과 펼쳐볼 수 있는 범위·출처를 표시한다. 기존 중국풍 색상·명조체·용어 Popover를 재사용한다.
- 서버 액션: 명반과 풀이를 함께 반환하며, 풀이 준비 실패는 내부 정보를 포함하지 않는 오류로 처리한다.
- 입력·결과 화면: 한 상태에 명반과 풀이를 보관해 서로 다른 결과가 섞이지 않도록 한다. 로딩·이용 목적·공통 읽는 법의 문구를 현재 기능에 맞췄다.

주성이 하나면 해당 별의 기본 의미를 표시한다. 동궁이면 개별 설명과 조합 해석 미지원 안내를 함께 표시한다. 주성이 없으면 현재 성향 풀이 미지원임을 설명하고 다른 궁의 별을 임의로 빌리지 않는다. 미지원 주성은 조용히 누락하지 않고 오류로 처리한다. 배열 순서가 달라도 같은 결과를 만든다.

새 패키지, 외부 AI 요청, 저장소, 범용 규칙 엔진과 미사용 AI 인터페이스는 추가하지 않았다. 현재 규칙 버전은 근거 추적용이다.

## 검증

단위 테스트는 독립 기준 명반의 명궁·주성 대조, 동명 보조성 제외, 주성 없음·단일·동궁 분기, 입력 불변성·참조 격리, 배열 순서 독립성, 14주성 지원, 미지원 별 거부와 서버 오류 정보 차단을 확인한다. 인위적으로 변경한 명반은 분기 검증용이며 독립 계산 기준으로 취급하지 않는다.

인앱 브라우저에서 1929-04-25 22:00의 실제 서버 계산 후 명궁 무곡·파군의 개별 풀이와 조합 미지원 안내를 확인했다. 첫 간편 진입, 상세 왕복 후 동일한 풀이 유지, 출처 펼치기와 글자·간격을 확인했다. 기존 기준 명반은 배치 검증 자료이며 풀이의 정확성을 입증하는 자료가 아니다.

이 작업에서 모바일 실기기·스크린리더·외부 전문가 평가는 수행하지 않았다. Node.js 24에서 124개 테스트·lint·타입 검사·운영 빌드와 변경 파일 포맷, `git diff --check`가 통과했다. 전체 저장소 포맷 검사는 이전에 확인한 별도 `.agents/` 파일 42개의 문제를 유지하며, 이번 작업에서 해당 파일이나 검사 설정을 변경하지 않았다.

## 요구사항 대조

명반 하단에 기본 풀이가 연결되었고 근거와 용어 설명, 탭 전환 시 재사용을 확인했다. 기본 풀이의 범위를 requirements.md에 기록했다. 입력 정책·계산·표시 별과 외부 전송·저장 여부는 유지한다. 이유 없는 요구사항 변경이나 수행 불가에 따른 축소는 없다.

## 남은 문제와 추후 개선점

주성 없는 명궁·동궁 조합의 성향 판단과 일·관계·재물의 주제별 풀이는 적용 조건·사례 검토 후 추가한다. AI는 검토된 근거만 설명하도록 도입하며 제공자·모델·데이터 처리와 평가 기준은 이후 결정한다. 저장·공유와 전체 독립 계산 검증은 기존 후속 항목이다.
