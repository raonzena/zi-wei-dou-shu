# 출생 정보 수정과 계산 기준 안내 구분

- 작성일: 2026-09-13
- 상태: 완료

## 작업 개요와 요구사항

사용자 요청에 따라 결과 하단의 출생 정보 수정 버튼과 계산 기준 안내를 시각적으로 구분한다. 기존 버튼 위치와 계산 기준 안내의 내용을 유지한다.

## 결정과 근거

계산 기준 안내는 이미 footer로 분리되어 있지만 borderTop이 0이다. 기존 colors.line을 사용한 1px 구분선과 상단 바깥 여백 1.5rem, 안쪽 여백 1rem을 적용한다.

## 변경 내용과 영향

공통 CalculationNotice 스타일을 변경해 종합 풀이와 상세 명반 모두 적용한다. 기능과 문구는 바꾸지 않는다.

## 검증

타입 검사와 git diff --check를 통과했다. 변경 파일은 Prettier로 정리했다. 스타일만 변경하므로 새 테스트는 추가하지 않았으며 브라우저 시각 검증은 수행하지 않았다.

## 요구사항 대조

요구사항과 화면 흐름에 버튼과 안내 사이의 구분을 명시했다. 안내가 하단에 한 번 표시되는 기존 요구사항을 유지한다.

## 남은 문제와 추후 개선점

이번 구분 작업에 미결정 사항은 없다.
