# 출생 정보 숫자 입력 제한

- 작성일: 2026-09-18
- 최종 갱신일: 2026-09-18
- 상태: 구현·검증 완료

## 작업 개요

생년월일과 출생 시각 입력란에 한글 입력기나 붙여넣기로 문자가 들어와 입력 상태가 불안정해지는 문제를 방지한다. 숫자 필드는 숫자와 기존 자릿수 제한만 허용하고, 이름 또는 닉네임의 한글 입력은 유지한다.

## 요구사항

- `REQ-01`에 따라 날짜와 시각의 목록 선택과 직접 입력을 유지한다.
- 연도는 숫자 4자리, 월·일·시·분은 숫자 2자리까지만 입력 상태에 남긴다.
- 클라이언트 정규화를 우회한 요청은 기존 서버 검증에서 계속 거부한다.

## 결정과 근거

`inputMode="numeric"`는 모바일 키보드 종류를 안내할 뿐 입력 문자를 제한하지 않는다. `NumberChoice`의 제어 값에 숫자 정규화를 적용해 키보드 입력과 붙여넣기를 같은 규칙으로 처리한다. `type="number"`는 브라우저별 입력 동작과 자릿수 제한이 달라 현재 자동완성 목록 구조에 사용하지 않는다.

## 변경 내용과 영향

- 숫자 필드 값에서 숫자가 아닌 문자를 제거한 뒤 기존 최대 자릿수를 적용한다.
- 숫자 입력 패턴을 명시해 지원하는 모바일 브라우저가 숫자 키패드를 제공하도록 돕는다.
- 이름 또는 닉네임 입력과 서버의 최종 검증에는 영향을 주지 않는다.

## 검증

- 숫자 정규화와 기존 제출 경계 테스트 27개가 통과했다.
- 프로젝트 포맷 검사, ESLint와 TypeScript 검사가 통과했다.
- 전체 테스트 315개가 통과했고 1개는 기존 설정대로 제외됐다.
- 통합 `pnpm check`는 실행 환경의 pnpm 11 선택으로 중단됐으며, 프로젝트가 지정한 pnpm 10.33.2로 동일한 포맷·린트·타입·전체 테스트 명령을 각각 실행해 검증했다.

## 요구사항 대조

목록 선택과 직접 입력을 유지하면서 숫자 필드의 허용 문자만 명확히 제한했다. 기존 `REQ-01`의 서버 검증과 자릿수 제한을 변경하지 않았다.

## 남은 문제와 추후 개선점

현재 작업 범위에서 확인된 문제는 없다. 브라우저마다 숫자 키패드 모양은 다를 수 있지만, 실제 입력값은 같은 정규화 규칙을 거친다.
