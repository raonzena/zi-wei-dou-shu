# 상세 명반 읽기 안내와 별 설명

- 작성일·최종 갱신일: 2026-09-12
- 상태: UI 구현 완료 · 전체 번역과 DB 도입은 제안

## 작업 개요

간편 기본 풀이의 제공 범위를 확인하고 상세 화면에 공통 읽기 안내, 선택한 궁의 접힌 주성 풀이와 별 설명을 연결한다. 출생 정보 수정 버튼을 구분선 아래·계산 안내 위에 배치한다.

## 요구사항

REQ-03·04·07과 사용자의 이번 요청을 따른다. 같은 명반을 재사용하며 추가 AI 호출은 하지 않는다. DB 도입은 사용자 질문에 대한 검토이며 확정된 구현 요구로 취급하지 않는다.

## 결정과 근거

기본 풀이는 기존 명궁 주성의 세 문단으로 한정되어 있으며 주성 없는 명궁은 안내만 제공한다. 종합 풀이 완료를 의미하지 않는다. 기존 iztro-docs 기반 한국어 콘텐츠와 용어집을 재사용한다. 원문 전체 번역이라고 표시하지 않는다. 공식 iztro 14주성 문서는 궁의 역할, 단일 별·쌍성·공궁을 구분한다. 이 구분을 읽기 안내에 적용한다. 기존 제품 내 details/summary 패턴을 유지한다.

DB는 배포 없는 편집·검수·발행이 필요할 때 적합하다. 현재 고정 콘텐츠는 파일로 관리해 불필요한 조회와 권한 설계를 추가하지 않는다. 후속으로 전체 번역을 도입한다면 별 식별자·언어·원문 URL/버전·번역문·검수 상태·발행 버전·저작권 고지를 관리하는 방안을 제안한다. 실제 테이블·DB 쓰기는 수행하지 않는다. iztro-docs의 MIT 라이선스와 기존 THIRD_PARTY_NOTICES.md의 고지를 확인했다.

## 변경 내용과 영향

공통 ReadingGuide를 두 탭에 연결한다. 상세 궁 풀이와 별 목록은 기본 접힘으로 제공하고 주성은 기존 세 문단, 보조성은 기존 짧은 설명을 출처와 함께 표시한다. 상세 주성 풀이의 네 문장과 궁 설명은 유지한다. 수정 버튼 위에 구분선을 배치한다.

## 검증

`pnpm check` 통과: 테스트 242개 통과, 유료 실평가 1개 건너뜀. `pnpm build` 통과. SSR 테스트로 접힘 상태와 설명·출처를 확인했다. 실제 브라우저 조작·시각 검증은 수행하지 않았다. 최종 구분선 위치와 사화 설명 수정 후 관련 SSR 테스트 3개와 빌드도 통과했다.

## 요구사항 대조

REQ-03·04·07 및 화면 흐름과 대조했고 사용자 요청을 반영했다. 기존 상세 풀이의 문장 수와 표시 범위는 유지했다. 상세 안내는 학습을 위한 기본 의미이며 궁·별 조합의 종합 해석으로 확대하지 않는다.

## 남은 문제와 추후 개선점

보조성 원문 전체 번역·검수와 DB 편집 기능은 미구현 제안이다. 현재 보조성 설명의 길이는 기존 용어집 수준이다. AI 품질 검증은 별도 작업으로 유지한다.
