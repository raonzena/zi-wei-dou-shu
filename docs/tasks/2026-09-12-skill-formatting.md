# 스킬 문서 포맷 경고 정리

- 상태: 완료
- 요구사항: 사용자 포맷 경고 정리 요청, AGENTS.md의 검증 규칙

## 결정과 변경

설치된 .agents/skills의 Prettier 경고 파일 42개를 포맷했다. 외부 스킬의 명령·의미를 바꾸지 않고 Markdown 줄바꿈, 표 정렬, YAML 포맷을 맞췄다. 원본 소스의 버전을 기록하는 skills-lock.json은 갱신하지 않았다. 폴더 쓰기 보호로 실패한 후 해당 경로의 명시적 권한을 받아 수정했다.

## 검증과 요구사항 대조

pnpm format:check 통과. 검사 제외나 경고 무력화 없이 기존 검사 범위를 유지했다. 제품 요구사항 변경은 없다. Python 스크립트는 수정하지 않았다.

## 남은 문제

상위 스킬을 다시 설치하면 원본 포맷으로 돌아올 수 있으므로 그때 동일 검사를 실행한다. 스킬 동작 자체를 재평가한 작업은 아니다.
