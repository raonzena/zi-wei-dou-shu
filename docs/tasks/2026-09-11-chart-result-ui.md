# 입력 문구 개선과 간편·상세 명반 UI

- 작성일: 2026-09-11
- 상태: 구현 완료 / 데스크톱 브라우저 검증 완료 / 모바일 실기기 검증 대기

## 작업 개요

입력 화면의 어색한 문구를 fluent-korean 지침에 맞게 수정한다. 기존 미리보기를 간편·상세 명반으로 확장하고, 궁 선택과 용어 설명을 연결한다.

## 요구사항

REQ-01·03·04·05·07·08·09·10과 OPEN-04에 해당한다. 첫 결과는 간편 명반으로 표시하고, 상세 탭에서도 같은 계산 데이터를 사용한다. 전문용어는 마우스·터치·키보드로 설명을 확인할 수 있어야 한다. 이번 단계에서 개인화 해석과 저장·공유를 완료한 것으로 처리하지 않는다.

## 결정과 근거

기존 화면의 12궁 배치와 보라색 계열을 유지한다. 바탕 #faf9f6, 본문 #202020, 강조 #645277, 선택 배경 #eee6f5, 구분선 #cec5d6, 궁 바탕 #ffffff를 사용한다. 기존 시스템 글꼴을 유지하고 제목·궁 이름·별 목록의 크기를 구분한다. 일반적인 카드 나열 대신 지지의 위치가 고정된 4×4 명반을 시각적 중심으로 삼는다.

간편 화면은 궁 이름과 14주성, 신궁, 오행국을 표시한다. 상세 화면은 궁을 선택하고 아래에서 간지, 한자 이름과 사화를 읽는 구조로 설계했다. 모바일에서 모든 별을 작은 칸에 넣어 축소하지 않는다. 표시 범위는 기존 독립 대조의 14주성과 보조성 16개에, iztro를 따르기로 확정한 화성·령성을 더한다. 밝기와 나머지 별의 표시·독립 검증은 후속 작업이다. 이는 이번 구현의 선정 범위이며 사용자가 세부 목록을 개별 지정한 것은 아니다.

설치된 Base UI 1.8.0의 Tabs와 Popover 문서·타입을 확인했다. 용어 설명에는 출처 링크와 닫기 버튼이 있으므로 Popover를 사용한다. hover와 클릭을 지원하고 키보드 포커스로도 연다. 별은 원본 category와 이름을 함께 사용해 천월(天鉞/天月), 천상(天相/天傷)을 혼동하지 않는다.

보기 모드는 URL의 view 값으로 관리하며 Next.js가 지원하는 History API와 useSearchParams를 사용한다. 탭 전환 시 서버를 다시 호출하지 않는다. 선택한 궁은 결과 전용 Jotai Provider에 보관하여 탭 사이에서 공유하고, 새 계산 시 초기화한다. 원본 출생 정보는 URL에 넣지 않는다.

용어 설명은 iztro의 궁·별·사화 설명을 바탕으로 짧게 요약한다. 별의 전통적인 의미를 설명하며 사용자 개인의 성격이나 미래를 단정하지 않는다. 전문가 감수나 개인화 해석 완료를 뜻하지 않는다.

## 변경 내용과 영향

입력 안내에서 생략된 주어와 조건을 보완하고, 계산 기준은 펼쳐 볼 수 있는 안내로 정리한다. 성별 기본값, 한국 음력 기준, 날짜·시각 입력 범위와 계산 정책은 유지한다. 오류가 없는 필드를 가리키는 aria-describedby 참조를 수정한다.

기존 preview 컴포넌트와 전용 스타일을 제거하고 chart 기능 모듈로 대체한다. 공통 용어집과 Term 컴포넌트를 만들고 실제 명반 데이터에 연결한다. 새 패키지는 추가하지 않는다.

## 검증

`pnpm lint`, `pnpm typecheck`, `pnpm test`의 117개 테스트와 `pnpm build`가 통과했다. 추가한 5개 테스트는 기준 명반의 32개 표시 별, 동명 별의 구분, 열 천간의 사화 보존과 원본 데이터 불변성, 궁의 배치, 결과별 선택 상태 격리를 검증한다.

전체 `pnpm check`는 이번 작업과 별개로 추가된 `.agents/` 파일 42개의 포맷 오류로 첫 단계에서 중단됐다. 해당 파일이나 검사 설정은 수정하지 않고, 이번 변경 파일의 Prettier 검사와 나머지 검사 명령을 각각 실행했다. 이를 전체 check 통과로 기록하지 않는다.

운영 빌드를 별도 로컬 포트에서 실행하고 인앱 브라우저로 확인했다. 실제 출생 입력에서 간편 명반이 먼저 열리고, 상세 탭의 궁 선택과 한자 이름 표시가 동작했다. 방향키로 탭을 전환하고 브라우저 뒤로 가기로 돌아와도 선택한 궁이 유지됐다. 입력 수정 시 값이 남았으며, 다시 계산하면 간편 탭과 명궁 선택으로 초기화됐다.

용어 설명은 클릭, 마우스 hover, Tab 포커스로 열렸고 Esc와 닫기 버튼으로 닫혔다. 닫은 뒤 원래 용어로 포커스가 돌아오는 것도 확인했다. 데스크톱 너비 1280px에서 스크린샷을 검토하고 가로 넘침이 없음을 확인했다.

모바일 실기기, Safari·Firefox, 스크린리더와 느린 네트워크는 이번 브라우저 검증에 포함하지 않았다. 작은 화면에서의 최종 사용성 검증은 남아 있다. 용어 설명의 전문가 감수나 전체 독립 명반 검증도 완료한 것으로 처리하지 않는다.

## 요구사항 대조

REQ-01·03·04·05·07·08·09·10과 requirements.md의 관련 수용 기준을 대조했다. 양력·한국 음력 입력, 남성 기본값, 시각 미상 제출 차단, 기존 계산 정책을 유지했다. 이유 없는 요구사항 변경이나 수행 불가에 따른 기능 축소는 없었다. 개인화 해석, 공유 버튼과 공개 링크, 영속 결과 라우트, 새로고침 후 결과 복원, 전체 독립 검증은 후속 작업으로 유지한다. 이번 UI를 전체 출시 완료로 처리하지 않는다.

## 남은 문제와 추후 개선점

개인화 해석은 근거와 생성 방식을 결정한 뒤 연결한다. 저장·소유권 정책이 정해지면 결과 라우트와 복원, 공유를 구현한다. 나머지 표시 항목은 독립 검증과 용어 설명을 함께 보완한다.
