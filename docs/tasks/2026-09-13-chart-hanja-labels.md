# 명반 이름 한자 병기

- 작성일: 2026-09-13
- 상태: 구현 완료

## 요구사항과 작업

사용자 요청으로 종합·상세 명반의 궁 이름과 주성 이름, 상세 궁 제목과 주성·보조성 분류에 한자를 병기한다. 상세 별 목록은 기존 한자 병기를 유지한다. REQ-07에 기록한다.

## 결정과 근거

설치된 iztro 2.6.1의 zh-TW/palace.js와 기존 glossary의 별 한자명을 확인했다. 노복은 현재 한국어 이름에 맞는 奴僕을 사용한다(iztro 번체 이름은 僕役). 주성·보조성 분류는 主星·補助星으로 표기한다. 별 이름은 기존 분류별 용어 데이터를 재사용한다. 작은 명반 칸에서 궁의 한자는 줄바꿈 가능한 작은 글씨로 표시한다. 계산·선택 동작과 DB는 변경하지 않는다.

## 검증과 요구사항 대조

타입 검사와 관련 궁 표시 테스트 5개, git diff --check를 통과했다. 첫 테스트 실행은 계산 fixture에서 5초 제한을 초과해 1개가 실패했으며, 코드·제한 시간 변경 없이 재실행해 5개 모두 통과했다. 실제 기기 시각 검증은 수행하지 않았다. 기존 종합 비선택·상세 선택 정책을 유지한다. 요구사항과 충돌하는 변경은 없다.
