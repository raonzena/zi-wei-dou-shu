## 작업 개요

사용자가 어색하다고 지적한 ‘태도로 읽을 수 있습니다’를 포함해 기본 풀이, 종합 풀이, 궁별 해석의 문장을 다듬는다.

## 요구사항

[요구사항](../requirements.md)의 쉬운 성향 설명과 상세 궁 해석의 4문장 구성을 유지한다. 사용자 요청에 따라 성향을 직접 설명하되, 미래 사건이나 질병을 확정하는 문장으로 바꾸지 않는다.

## 결정과 근거

전역 /Users/sulhwa/.codex/AGENTS.md에 설치된 fluent-korean 원문 지침을 확인했다. 완결된 문장, 충분한 조사와 어미, 문맥에 맞는 어휘를 적용한다. 14개 주성의 반복적인 우회 표현을 개별 문장으로 수정하고, 주의점의 조건과 가능성은 유지한다.

## 변경 내용과 영향

- palace-reading-rules: 주성 14개의 기본 성향과 궁의 생활 영역 설명을 다듬었다. 궁 해석과 종합 풀이에 함께 반영된다.
- basic-reading-rules: 주성의 의미·강점을 간결하게 설명하고 ‘소개됩니다’ 등의 간접 표현을 줄였다. 편집 버전은 ming-major-v4로 올렸다.
- palace-reading과 comprehensive-reading: 생활 활용 문장, 분야 연결 설명, 사화의 보충 설명을 다듬었다.
- 계산과 근거 연결 규칙은 변경하지 않았다. DB에 발행된 별 사전 번역과 AI 생성문은 이번 정적 풀이 문구 변경에 포함하지 않았다.

## 검증

기본·궁별·종합 풀이 기존 테스트 13개가 통과했다. 변경 파일을 Prettier로 정리했고 git diff --check를 통과했다. 반복되던 ‘태도로 읽을 수 있습니다’가 해당 소스에 남아 있지 않은 것도 확인했다. 문자열 변경이므로 전체 빌드와 유료 AI 실평가는 실행하지 않았다.

## 요구사항 대조

쉬운 문체 요구사항을 구체화했다. 궁별 상세 설명의 4문장 구성, 주성별 내용 범위, 주의점의 가능성 표현을 유지했다.

## 남은 문제와 추후 개선점

DB 별 사전과 AI 응답 문체의 별도 수정은 수행하지 않았다. 정적 풀이 변경의 효과를 확인하는 데 AI 호출은 필요하지 않다.
