# 무주성 궁의 대궁 참고 풀이

- 작성일: 2026-09-13
- 최종 갱신일: 2026-09-13
- 상태: 구현·코드 검증 완료

## 작업 개요

주성이 없는 궁에서 범위 안내만 나오고 실제 기본 풀이가 비어 있는 문제를 해결한다. GitHub `main`의 최신 상태를 확인한 뒤, 종합 풀이와 상세 명반 모두에서 맞은편 궁의 주성을 참고한 설명과 근거를 제공한다.

완료 기준은 무주성 사실·대궁 이름·참고 주성이 명확히 구분되고, 주성별 기본 문장이 표시되며, 기존 직접 주성 풀이와 저장 결과 읽기가 깨지지 않는 것이다.

## 요구사항

- REQ-03 / REQ-05: 명궁 기본 풀이와 일곱 분야 종합 풀이에도 무주성 참고 설명을 제공한다.
- REQ-04: 상세 명반에서 선택한 무주성 궁의 대궁 주성별 네 문장 풀이를 제공한다.
- 해석 정책: 참고한 대궁과 별을 밝히고 본궁 주성이나 검증된 조합 풀이로 표현하지 않는다.
- 사용자 지시: iztro를 가장 우선하는 구현 근거로 확인한다.

## 결정과 근거

GitHub `main`의 최신 커밋 `8de387d`와 열린 PR이 없음을 먼저 확인했다. iztro 2.6.1의 설치 소스에서 명궁이 공궁이면 `soulIndex + 6` 위치의 주성을 반환하는 구현을 확인했다. 같은 버전의 궁 분석기는 지지 위치에서 여섯 칸 떨어진 궁을 대궁으로 제공한다.

서비스는 저장 가능한 순수 Chart JSON을 사용하므로 엔진 객체를 다시 만들지 않고, iztro와 같은 지지 순서 및 `+6` 계산을 적용한다. 자세한 결정과 범위는 ADR-0005에 기록한다.

## 변경 내용과 영향

- `findOppositePalace`가 iztro와 같은 지지 순서에서 여섯 칸 떨어진 대궁을 찾는다.
- 명궁 기본 풀이는 직접 주성이 없을 때 대궁 주성의 규칙 콘텐츠를 제공하고, 직접 근거와 대궁 참고 근거를 분리한다. 풀이 버전은 `ming-major-v5`다.
- 일곱 분야 종합 풀이와 상세 궁 풀이도 무주성 궁에서 대궁 주성의 기본 의미를 표시한다.
- 세 화면 모두 본궁의 주성 없음, 대궁 이름, 참고 주성과 적용 한계를 표시한다. 본궁의 실제 보조성·사화 표시는 기존대로 유지한다.
- 저장 결과 스키마의 대궁 근거는 선택 필드로 추가해 이전 `ming-major-v4` 결과도 계속 읽는다.
- 요구사항과 화면 흐름의 과거 “대궁 주성을 사용하지 않는다”는 문장을 현재 결정으로 교체하고 ADR-0005를 추가했다.

## 검증

- iztro 2.6.1 설치 소스의 `getMajorStarBySolarDate`와 `getSurroundedPalaces` 구현을 확인했다.
- 무주성 명궁 고정 사례에서 서비스가 선택한 참고 주성 목록과 iztro의 명궁 주성 조회 결과가 일치하는지 자동 검사한다.
- 직접 주성·동궁·무주성·보조성 동명·원본 불변, 세 화면의 대궁 표기, 과거 저장 결과 파싱을 검사한다.
- `pnpm format:check`, ESLint, Next.js 타입 생성과 TypeScript 검사를 통과했다.
- 전체 Vitest 292개가 통과했고 유료 실평가 1개는 기존 설정대로 제외됐다.
- `pnpm build`를 통과했다.
- 실제 브라우저 조작 검증과 운영 배포는 아직 수행하지 않았다. 화면 문구는 React 정적 렌더링 테스트로 확인했다.

## 요구사항 대조

- REQ-03 / REQ-05: 간편 명궁 기본 풀이와 일곱 분야에 대궁 참고 풀이를 제공한다.
- REQ-04: 상세 명반의 무주성 궁에도 주성별 네 문장과 출처 궁을 표시한다.
- 해석 정책: 대궁 주성을 본궁 주성으로 기록하지 않고 참고임을 반복 표시한다.
- 저장 호환: 새 결과는 v5로 분리되고 이전 결과의 선택 필드 부재를 허용한다.

## 남은 문제와 추후 개선점

- 실제 화면의 모바일 가독성과 문단 길이는 배포 미리보기에서 추가 확인할 수 있다.
- 보조성·사화·밝기·삼방사정을 결합한 무주성 전문 해석은 검증된 규칙과 출처가 확정될 때 별도 작업으로 다룬다.
