# 종합 풀이의 명반과 상세 풀이 표시 정리

- 작성일: 2026-09-13
- 상태: 구현 완료

## 작업 개요와 요구사항

사용자 요청으로 종합 풀이의 명반 도식을 유지하면서 궁 선택과 선택한 궁의 풀이를 제거한다. 상세 명반의 ‘○○의 주성으로 읽는 나의 모습’은 항상 표시한다. REQ-03·04와 화면 흐름을 최신 지시로 갱신한다.

## 결정과 근거

기존 ChartRing·PalaceDetail을 확인했다. 종합 풀이의 궁은 버튼 대신 일반 요소로 표시해 클릭·키보드 선택과 선택 강조를 제거한다. 상세 명반은 기존 버튼과 선택 상태를 유지한다. 사용하지 않는 PalaceDetail의 간단 보기 옵션을 제거한다. 개별 별 설명과 풀이 근거의 접기 기능은 이번 요청 대상이 아니므로 유지한다.

## 변경과 영향

종합 풀이에서 궁 선택 안내와 PalaceDetail을 제거한다. 기본 풀이·일곱 분야 풀이·AI 해석·읽기 안내는 유지한다. 상세 궁의 주성 풀이를 details/summary 대신 일반 영역과 제목으로 표시한다. 저장 데이터·계산·AI 호출은 변경하지 않는다.

## 검증

pnpm check 통과(279개 통과, 유료 실평가 1개 제외), pnpm build와 git diff --check 통과. 최초 빌드는 삭제한 showTechnicalDetails 옵션을 기존 테스트가 사용해 타입 검사에서 실패했다. 종합 명반의 비선택 표시, 상세 명반의 12개 선택 버튼·선택 상태, 항상 표시되는 주성 풀이 제목을 검증하도록 테스트를 갱신했다. 마지막으로 사용하지 않는 PalaceReading의 간단 보기 옵션도 제거하고 관련 테스트 5개와 타입 검사를 다시 실행해 통과했다. 실제 브라우저 시각 검증은 수행하지 않았다.

## 요구사항 대조와 남은 사항

REQ-03·04의 종합 궁 선택과 상세 주성 풀이 접힘 요구를 사용자 지시에 맞춰 수정했다. 그 외 개별 별 설명과 근거 접힘 정책은 유지한다. 이번 범위에 추가 미결정 사항은 없다.

## 후속 문구 수정

사용자가 승인한 쉬운 표현으로 궁 풀이 하단 안내를 교체했다. “이 설명은 이 궁에 있는 주요 별을 바탕으로 작성했습니다. 명반 전체를 함께 살펴보면 더 다양한 모습을 발견할 수 있습니다.”로 표시한다. 주요 별에 한정된 설명이라는 범위는 유지하며 전문용어 나열을 제거한다. REQ-04의 쉬운 궁 설명 취지에 부합하고 계산·해석 규칙은 변경하지 않는다. 단순 문구 교체이므로 새 테스트는 추가하지 않고 포맷과 diff를 확인한다.

## 커밋 전 최종 검증

화면 단순화·문구 교정·출처 영역 조정과 운영 적용 SQL 기록을 함께 검토했다. 최종 코드에서 pnpm check(279개 통과, 유료 실평가 1개 제외), pnpm build, git diff --check를 통과했다. 관련 요구사항과 화면 흐름을 대조했다. 실제 화면 시각 검증은 기존에 기록한 미검증 범위로 유지한다. 이번 요청은 로컬 커밋이며 원격 푸시는 포함하지 않는다.
