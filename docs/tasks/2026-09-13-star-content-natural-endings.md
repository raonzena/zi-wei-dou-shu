# 별 설명 종결 표현 다듬기

- 작성일: 2026-09-13
- 상태: 운영 발행 완료

## 작업 개요와 요구사항

사용자 요청으로 ‘모습으로 풀이합니다’, ‘모습으로 설명합니다’를 자연스러운 한국어 문장으로 바꾼다. REQ-07 및 별 콘텐츠의 버전·검수·발행 관리 요구사항을 따른다.

## 결정과 근거

운영 발행본 조회에서 각각 8개와 6개를 확인했다. 기존 의미와 나머지 문장을 유지하며 첫 문장의 종결을 직접적인 행동 설명으로 바꿨다. 천귀는 긍정적 반응을 반드시 얻는다는 단정 대신 가능성을 유지한다. Codex 한국어 편집 검수이며 원문 재번역이나 전문가 검수가 아니다.

## 변경과 영향

20260913012000_star_content_natural_endings.sql에 14개의 명시적 문장 교체를 기록했다. 기존 발행본과 원문 출처·버전·라이선스를 보존하고 새 초안 생성 → 편집 검수 → 발행 함수 호출을 한 트랜잭션으로 수행했다. 기대한 기존 문장이 없으면 전체 작업을 중단한다. 운영 DB에 적용했으며 신규 결과에서 새 발행본을 사용한다. 이미 저장된 결과는 당시 설명을 포함하는 스냅샷이므로 기존 문구를 유지한다. 저장 결과를 임의 변경하지 않았다.

## 검증

운영 발행본 39개 유지, 버전 2 발행본 14개, 두 대상 표현이 남은 발행본 0개를 조회로 확인했다. 최초 조회에서 CLI에 없는 --sql 옵션을 사용했고 위치 인수로 수정했다. 최초 파일 생성은 Python 인코딩 오류로 실패해 DB 변경 없이 종료됐고 /usr/bin/python3과 UTF-8 선언으로 수정 후 적용했다. AI 호출과 앱 배포는 수행하지 않았다. SQL 파일 적용은 Management API 방식이며 CLI migration history 등록을 주장하지 않는다.

## 요구사항 대조와 남은 사항

설명의 뜻과 출처를 보존하고 이전 버전을 덮어쓰지 않았다. 요구사항 변경은 필요하지 않다. 기존 결과는 저장 당시 콘텐츠를 유지하는 정책에 따라 이전 문구가 보일 수 있다. 이번 문구 변경의 미결정 사항은 없다.

## 후속 확인: 성향으로 풀이합니다

사용자 추가 요청에 따라 코드와 현재 발행본의 ‘풀이합니다’를 다시 검색했다. src에는 없고 주성 14개의 첫 문장에 ‘성향으로 풀이합니다’가 남아 있었다. 별이 나타내는 성향이라는 의미를 유지하도록 ‘성향을 나타냅니다’로 수정했다. 20260913013000_major_star_natural_endings.sql을 운영에 적용해 검수 후 버전 2로 발행했다. 기존 버전·원문·라이선스는 보존했다.

검증: 운영 발행본 39개 유지, 주성 버전 2 발행본 14개, ‘풀이합니다’가 남은 발행본 0개를 확인했다. src 검색 결과도 0건이다. 이전 마이그레이션과 보관된 설명 이력은 변경하지 않으며, 기존 저장 결과에는 당시 문구가 남을 수 있다. REQ-07 및 콘텐츠 버전 관리 정책과 대조했고 요구사항 변경은 없다.

## 재확인: ~으로 풀이합니다

사용자 요청으로 src와 운영 발행본을 재조회했다. ‘풀이합니다’(중간 공백 포함)와 ‘~으로 풀이합니다’에 해당하는 현재 발행본은 없다. 앞선 교정이 이미 적용된 상태이므로 불필요한 새 버전을 생성하지 않는다. 과거 버전과 기존 저장 결과는 이력 보존 정책을 유지한다. 사용자에게 보이는 정확한 이전 문구의 위치는 이번 요청에 제공되지 않아 특정 결과로 단정하지 않는다.

## 후속 교정: 해설을 전달하는 어투 제거

사용자는 ‘풀이합니다’를 ‘설명합니다’로만 바꾸는 것으로는 충분하지 않으며, ‘별입니다’, ‘모습도 있습니다’처럼 직접 설명하도록 요청했다. src와 운영 발행본을 검색하고 15개 별 설명의 16개 문장을 문맥별로 교정했다. 팔좌의 두 문장은 사용자가 제시한 문구를 그대로 적용했다. 파군에 원문에 없는 계획·준비 성향을 더하지 않고 행동만 앞서는 것은 아니라는 의미를 유지했다.

20260913014000_star_content_direct_voice.sql은 같은 별의 여러 교정을 묶어 새 버전 하나로 검수·발행한다. 운영 적용 후 전체 발행본 39개 유지와 대상 해설 표현 잔여 0개, 팔좌의 두 문장 교정을 확인했다. 원문·출처·라이선스·이전 버전과 저장 결과는 보존한다. 요구사항과 콘텐츠 관리 문서에 직접적인 어투와 의미 보존 원칙을 추가했다. AI 호출과 앱 배포는 하지 않았다.
