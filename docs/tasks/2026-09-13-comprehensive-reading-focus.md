# 종합 풀이의 해석 중심 문장

- 작성일: 2026-09-13
- 최종 갱신일: 2026-09-13
- 상태: 구현·검증 완료

## 작업 개요

간편 종합 풀이에서 실제 별 해석보다 `이 영역에서는`, `살펴봅니다`, `~해보세요` 같은 구조 안내와 행동 지시가 더 자주 보이는 문제를 해결한다. 각 생활 분야를 일반 사용자의 질문, 별의 실제 성향, 구체적인 생활 장면 순서로 읽을 수 있게 바꾼다.

## 요구사항

- REQ-03 / REQ-05의 종합 풀이를 대상으로 한다.
- 상세 명반의 항목별 7~8문장 요구와 데이터는 변경하지 않는다.
- 명궁 기본 풀이에서 이미 설명한 같은 성향은 종합 풀이에서 반복하지 않는다.
- 주성이 없는 궁은 iztro 2.6.1과 같은 맞은편 궁 참조 원칙과 한계 안내를 유지한다.

## 결정과 근거

문제의 문장은 상세 명반이 아니라 `ComprehensiveReading`이 궁 설명, 별 조합, 사화 설명, 실천 문장을 연속해서 출력하면서 생겼다. 종합 풀이에서는 균형점과 궁별 실천 문장을 제거하고, 검수된 별·쌍성 해석 및 생활 예시를 본문에 표시한다. 사화도 해석 방법을 안내하지 않고 나타날 수 있는 관심·책임·평가·부담의 모습을 직접 설명한다.

## 변경 내용과 영향

- 일곱 분야의 소개를 사용자가 궁금해하는 내용 중심으로 교정했다.
- 열두 궁의 제목을 질문형으로 바꾸고 궁별 생활 예시를 추가했다.
- 단일 주성과 두 주성 조합의 검수된 예시를 종합 풀이에 표시한다.
- 반복되던 균형점, 궁별 실천 지시와 추상적인 궁 설명을 종합 풀이 본문에서 제거했다.
- 무주성 궁의 맞은편 주성 근거와 해석 한계는 유지했다.

## 요구사항 대조

종합 풀이는 실제 성향과 생활 예시를 중심으로 표시하고, 상세 명반의 7~8문장 구성은 그대로 유지한다. 명궁 중복 방지와 무주성 궁의 맞은편 참조도 유지한다.

## 남은 문제와 추후 개선점

운영 배포 후 실제 모바일 화면에서 문단 길이와 분야별 생활 예시가 충분히 구분되는지는 추가로 확인할 수 있다.
