# 종합 풀이 탭 명칭 변경

- 작성일: 2026-09-13
- 최종 갱신일: 2026-09-13
- 상태: 완료

## 작업 개요

명반과 여러 생활 영역의 해석을 함께 제공하는 화면을 사용자가 이해하기 쉽도록 ‘간편 명반’에서 ‘종합 풀이’로 이름을 바꾼다.

## 요구사항

사용자가 확정한 ‘종합 풀이 | 상세 명반’ 명칭을 적용한다. REQ-03·REQ-05의 첫 진입과 보기 전환 동작은 유지한다.

## 결정과 근거

사용자가 승인한 명칭 변경이다. 기존 화면 구성과 탭 구현을 확인했으며 새로운 설계나 패키지는 필요하지 않다. 내부 보기 값 simple/detail은 표시 이름이 아니므로 그대로 유지한다.

## 변경 내용과 영향

화면 탭, 관련 테스트 설명, requirements.md와 screen-flow.md의 현재 화면 명칭을 맞췄다. 명반 도식 자체의 간소화 여부를 설명하는 표현과 과거 작업 기록은 보존했다.

## 검증

변경 파일을 Prettier로 정리하고 git diff --check를 통과했다. 표시 문자열만 바꾸므로 새 테스트와 AI 호출은 필요하지 않다.

## 요구사항 대조

명칭만 사용자 결정에 따라 변경했다. 최초 표시, 상세 전환, 계산 결과 재사용과 풀이 내용은 동일하다.

## 남은 문제와 추후 개선점

이번 명칭 변경 범위에 남은 문제는 없다.
