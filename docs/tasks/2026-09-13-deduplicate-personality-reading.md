# 명궁 성향 풀이 중복 제거

- 작성일: 2026-09-13
- 최종 갱신일: 2026-09-13
- 상태: 구현·검증 완료

## 작업 개요

종합 풀이에서 명궁 주성 조합의 같은 제목과 설명이 기본 성향, 명궁, 명궁을 맞은편으로 참고하는 천이궁에 반복되는 문제를 해결한다.

## 요구사항

- 명궁 주성의 기본 성향과 조합 설명은 ‘나를 알아보는 기본 풀이’에서 한 번만 표시한다.
- 일곱 분야 종합 풀이에서는 명궁의 성향 문장을 반복하지 않고 해당 궁의 생활 맥락과 함께 볼 특징에 집중한다.
- 명궁을 맞은편 참고 궁으로 사용하는 무주성 궁도 같은 설명을 다시 표시하지 않는다.
- 명궁 외 다른 궁의 두 주성 조합 요약은 유지한다.

## 결정과 근거

사용자가 제공한 운영 결과에서 천기·거문의 ‘여러 가능성을 따져 말로 풀어내는 모습’ 제목과 본문이 기본 풀이, 명궁, 무주성 천이궁에 세 번 표시되는 것을 확인했다. 세 위치는 같은 별 조합을 출처로 사용하므로 성향 설명을 반복하는 대신 기본 풀이를 한 번 참조한다. 결과 접근 ID와 출생 정보는 문서나 테스트에 남기지 않는다.

## 변경 내용과 영향

- 종합 풀이의 각 궁에 주성의 실제 출처가 명궁인지 나타내는 값을 추가했다.
- 명궁과 명궁을 맞은편으로 참고하는 무주성 궁에서는 주성·조합 본문을 다시 출력하지 않고 위 기본 풀이를 안내한다.
- 궁의 생활 영역 설명, 사화·보조성·삼방사정 근거와 실천 문장은 그대로 유지한다.
- 명궁 외 다른 궁의 단일 주성 및 두 주성 조합 풀이는 기존과 동일하게 표시한다.

## 검증

- 운영 결과 페이지에서 ‘여러 가능성을 따져 말로 풀어내는 모습’ 제목과 본문이 세 번 표시되는 것을 재현했다.
- 같은 명궁 조합 제목이 기본 풀이와 종합 풀이 전체에서 한 번만 렌더링되는 회귀 테스트를 추가했다.
- 명궁을 맞은편으로 참고하는 무주성 궁에도 중복 방지가 적용되는지 확인했다.

## 요구사항 대조

- 명궁의 주성 조합 설명은 기본 풀이에서 한 번만 표시한다.
- 종합 풀이의 명궁과 명궁을 참고하는 무주성 궁은 생활 영역별 설명만 이어서 제공한다.
- 열두 궁·일곱 분야 구성과 다른 궁의 조합 풀이는 유지한다.

## 남은 문제와 추후 개선점

- 현재 중복 판정은 별 이름 문자열이 아니라 주성의 출처 궁이 명궁인지로 구분한다. 따라서 우연히 다른 궁에 같은 주성 조합이 놓인 경우에는 그 궁의 생활 맥락상 필요한 별 설명을 유지한다.
