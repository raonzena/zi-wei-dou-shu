# 상세 명반에서만 판독 요약 표시

- 작성일·최종 갱신일: 2026-09-12
- 상태: 구현·코드 검사 완료

## 작업과 요구사항

사용자 요청에 따라 명반 판독 요약을 간편 명반에서 제거하고 상세 명반에서만 표시한다. 관련 요구사항은 REQ-03·05·07의 결과 화면과 탭 전환이다.

## 결정과 변경

`ChartResult`의 간편 탭에서 `ChartFacts`를 제거했다. 상세 탭에서는 궁별 상세 내용 다음에 기존 요약을 제공하며 기본적으로 접힌 상태를 유지한다. 간편 화면은 명반·기본 풀이·활성화된 해석을 표시한다. 요약을 옮겨도 AI 해석에서 사용하는 근거 자료는 그대로 전달한다.

간편 화면에서만 쓰던 번호 표시·자동 펼침 옵션 `numbered`는 호출 경로가 없어져 제거했다. 데이터 계산, 탭 전환과 AI 호출 동작은 바꾸지 않았다.

## 검증

변경 파일의 포맷·린트, `pnpm typecheck`, `git diff --check`가 통과했다. 요약 컴포넌트가 상세 패널에만 남아 있고 numbered 참조가 제거된 것을 확인했다. 표시 위치 변경이므로 새 단위 테스트나 유료 AI 호출은 추가하지 않았다. 브라우저 화면 검증은 수행하지 않았다.

## 요구사항 대조와 남은 작업

사용자가 정한 화면 구성을 requirements.md와 screen-flow.md에 반영한다. 상세 자료 제공 기능은 유지되며 요구사항 축소는 없다. AI 비활성 상태와 Supabase 운영 연결 대기는 유지한다. 배포는 이번 작업에 포함하지 않는다.
