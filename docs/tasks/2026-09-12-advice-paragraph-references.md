# 해석 문단과 조언의 참조 구조

- 작성일·최종 갱신일: 2026-09-12
- 상태: 구현 완료 · 실제 AI 응답 미검증

## 개요와 요구사항

사용자가 본문은 성향 설명에 집중하고 조언은 별도 목록에서 해석 문단을 참조하며, 추가 궁의 관련성·해석을 분리하는 방안을 승인했다. requirements.md AI 해석과 screen-flow.md 결과 화면을 함께 갱신한다. 실제 AI 호출·커밋·배포는 이번 요청에 포함하지 않는다.

## 결정과 근거

기존 nullable adviceLink는 일반 문단에 조언이 들어가도 누락을 기계적으로 확인할 수 없었다. 조언은 text·paragraphId·reason의 독립 객체로 만들고 같은 분야의 해석 문단만 참조한다. 현재 최대 3문단 범위에 맞춰 p1·p2·p3을 사용한다. 문단 번호는 해당 분야 안에서만 유효하며 다른 분야의 같은 이름을 참조하는 경로는 없다.

근거는 relevance(이 주제와의 관련성)·interpretation(그 관계로 읽은 경향)으로 구분한다. 모든 인용에 두 값을 요구해 주제 관련성을 생략하지 않도록 한다. 의미 판정 모델이나 추가 API를 넣지 않고 strict Zod 객체와 존재 참조 검사만 수행한다. 이전 interpretationLink·adviceLink 경로는 제거한다.

## 변경과 영향

- section.paragraphs에 고유 id를 추가하고 bulletPoints는 같은 분야의 paragraphId와 비어 있지 않은 reason을 필수로 받는다.
- 제목·요약·본문은 성향과 생활 모습, 조언은 bulletPoints로 제한하도록 프롬프트를 수정했다. 건강의 의료진 상담 안내도 해당 분야의 조언에 작성한다. grounded-passages-v4로 변경했다.
- 명반 근거는 관련성과 해석을 두 줄로 구분한다. 조언은 접힌 풀이 근거 안에서 ‘조언 N · 문단 M에서 이어지는 조언’과 이유를 보여준다. 참조된 문단의 배치 근거는 위 문단 근거에서 확인할 수 있다.
- 없는 문단·다른 분야 문단·중복 문단 ID·빈 조언 이유·빈 관련성·이전 조언 evidence 구조를 거부한다. 조언이 없는 분야는 빈 목록을 허용한다. 기존 ID 중복 제거와 미성립 격국 제외는 유지한다.

## 검증

Node.js 24와 pnpm 10.33.2에서 `pnpm check`와 `pnpm build`가 통과했다. 테스트 242개가 통과했고 유료 실평가 1개는 건너뛰었다. 참조 범위·중복·누락 경계와 HTML에서 접힌 조언 연결 표시를 검사했다. 브라우저 시각·키보드 검증과 추가 AI 호출은 수행하지 않았다.

## 요구사항 대조와 한계

합의한 구조를 요구사항·프롬프트·검증·화면에 반영하고 대조했다. 이유 없이 요구사항과 달라진 부분은 없다. 본문에 조언을 넣지 않도록 지시하지만 문장 의미를 완벽하게 분류하는 검사는 아니다. 관련성이나 이유의 설득력을 자동으로 승인하지 않는다. 새 구조의 실제 모델 준수율은 미검증이며 추가 실평가가 필요하다. 이전 실패를 숨기거나 요구사항을 완화하지 않는다.
