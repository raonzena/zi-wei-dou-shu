# 별 설명 콘텐츠의 DB 관리

- 작성일·최종 갱신일: 2026-09-12
- 상태: 운영 저장·발행 완료

## 작업 개요와 요구사항

사용자가 요청한 원문 출처·버전, 한국어 번역문, 검수·발행 상태를 Supabase에서 관리한다. REQ-04·07의 상세 별 설명에 발행본만 연결한다. 종합 풀이 확장은 별도 범위 확인 중이다.

## 결정과 근거

Supabase 공식 RLS 문서의 읽기 전용 공개 콘텐츠 패턴을 따른다. 버전별 행을 보존하고 별·언어마다 한 버전만 발행한다. 편집·검수·발행은 Supabase 대시보드의 관리자 권한으로 수행하며 일반 사용자에게 쓰기 권한을 주지 않는다. 원문 버전과 번역 버전을 구분하고 검수를 수행하지 않은 초안을 검수 완료로 표시하지 않는다.

## 변경 내용과 영향

star_content 버전 테이블, RLS·공개 컬럼 권한, 검수·발행 상태 전이 트리거와 원자적 발행 함수를 추가했다. 기존 주성 14개를 원문에 대조하고 보조성 25개의 설명을 보강해 초기 발행본으로 저장했다. 원문 버전은 431611d05ef5f910f936c3d4c32aec7de2027d96이며 해당 별의 원문 구간을 보존한다. Codex 편집 검수 범위를 기록했으며 전체 직역이나 전문가 검수로 표시하지 않는다. 공개 키를 쓰는 서버 조회와 화면 컨텍스트를 연결했다. 운영 절차는 [콘텐츠 관리](../star-content-management.md)에 작성했다.

## 검증

격리 Docker Postgres에서 39개 초기 초안, 공개 RLS·쓰기 차단·검수 메모 비공개, 미검수 발행 차단, 발행 이력 수정 차단, 발행본 중복 차단과 버전 교체·재검수 초기화가 통과했다. 초기 서버 준비 중 임시 DB가 종료되는 테스트 준비 오류는 TCP 접속으로 대기하도록 수정했다. 운영 프로젝트 zequziabehplkeaufjcq에 Supabase Management API를 사용하는 CLI db query로 마이그레이션을 적용했다. 운영 공개 키로 발행본 39개 조회와 검수자 컬럼 조회 거부를 확인했다. 기존 운영 DB에는 supabase_migrations.schema_migrations가 없어 db push 이력 등록 완료로 주장하지 않는다. 브라우저에서 DB 설명·버전·출처와 Enter로 열고 닫기를 확인했다.

## 요구사항 대조

REQ-04·07과 신규 콘텐츠 관리 요구사항을 대조했다. 발행본만 표시하며 DB 오류 시 기존 파일 설명으로 대신하지 않는다. 요구사항을 낮추거나 미검수 자료를 전문가 검수로 표시하지 않는다.

## 남은 문제와 추후 개선점

현재 관리 UI는 Supabase 대시보드이며 별도 서비스 관리자 페이지는 없다. 39개는 편집 설명이며 모든 원문 조합·잡요의 전체 번역과 전문가 검수는 후속 범위다. DB 적용은 완료했지만 애플리케이션 배포·커밋·푸시는 하지 않았다.
