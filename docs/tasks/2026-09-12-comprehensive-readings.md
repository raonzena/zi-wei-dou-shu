# 종합 기본 풀이와 AI 해석

- 작성일·최종 갱신일: 2026-09-12
- 상태: 종합 기본 풀이 확장 완료 · AI 의미 품질 보완 중

## 작업 개요와 요구사항

사용자가 종합 기본 풀이와 AI 해석 모두 완성하는 방향을 선택했다. 본명반 일곱 분야에서 열두 궁을 함께 읽되 전문적인 근거는 접힌 영역에 분리한다. 시기별 운세는 기존 미지원 범위를 유지한다.

## 결정과 근거

기존 개별 주성 풀이에 분야별 연결을 얹는다. 실제 배치와 발행된 별 설명을 사용하고, 없는 조합 규칙을 만들어 전문 검증으로 주장하지 않는다. 해석의 종합 수준과 실제 AI 평가를 구분한다.

## 변경 내용과 영향

간편 화면에 일곱 분야로 열두 궁을 구분한 기본 풀이를 연결했다. 주성의 기본 모습·강점·주의점, 발행된 보조성 설명, 생년사화와 원문에서 확인한 두 보조성 동궁 조합을 표시한다. 삼방사정은 실제 비교 대상만 표시하고 기계적인 조언으로 확대하지 않는다. 이는 모든 쌍성·격국·연쇄 비화를 처리하는 종합 엔진의 완성을 뜻하지 않는다. AI는 발행 콘텐츠를 natal-reading-v3 입력에 포함하며 같은 스냅샷을 호출 중복 식별에 사용한다. grounded-passages-v5로 1회 실평가한 후 미인용 별 검증·두 문단 4~5문장 지시를 보강한 v6로 변경했다.

## 검증

pnpm check에서 테스트 248개가 통과하고 유료 평가 1개는 기본 검사에서 건너뛰었다. 빌드도 통과했다. 브라우저에서 AI 비활성 입력 → 종합 기본 풀이 → 상세 탭 → 발행된 보조성 설명의 키보드 열기·닫기를 확인했다. v5 실호출 1회는 50.078초, 입력 21,906·출력 7,990토큰, 코드의 가격 스냅샷 기준 약 $0.052385였다. 당시 구조 검사는 통과했지만 모든 분야 본문이 6문장이고 일부 근거 누락과 추상적 연결·건강 본문의 조언 혼입이 남았다. 후속 v6 검증을 포함해 실제 호출은 총 2회 수행했다. 응답은 무시되는 work/ai-evaluations/reference-1789223320343.json에 저장했다. 새 검증기로 같은 응답을 재검사하여 본문 1곳·조언 이유 4곳의 미인용 별을 검출했다. v6 실호출은 47.403초, 입력 21,975(캐시 4,352)·출력 7,426토큰, 약 $0.046961였다. 일곱 분야가 모두 두 문단·4문장으로 개선됐고 미인용 별이 포함된 본문은 없어졌지만 조언 이유 4곳에서 남아 invalid-response로 차단됐다. 전체 유료 비용은 코드 가격 스냅샷으로 약 $0.099346이다. v6 응답은 work/ai-evaluations/reference-1789223948222.json에 보존했다.

## 요구사항 대조

REQ-03·04·07 및 해석 품질 요구사항에 대조하여 기본 풀이의 확장 범위·DB 발행본 사용·AI 별 이름 대응 검사와 문장 수 품질 평가를 기록했다. AI 의미 품질을 완료로 낮춰 보고하지 않는다. 운영 AI는 비활성을 유지한다.

## 남은 문제와 추후 개선점

새 구조를 지키는 모델 생성과 의미 품질은 미해결이다. 현재 이름 검사는 알려진 별 이름의 문자 등장과 근거 배치의 대응이며 의미 판정이 아니다. 문장 수는 품질 플래그이고 서버의 의미적 합격 판정이 아니다. v6에서 문장 수와 본문 별 대응은 개선됐지만 조언 이유의 범위 준수는 미해결이다. 반복 실호출을 계속하기보다 조언 생성의 국소적 근거 사용을 보완한 뒤 다음 평가를 해야 한다.

실제 실패 예: 커리어 p2 조언 이유는 “천기·태음의 조정 능력과 파군의 수정 성향이 함께 있어, 진행 중 수정이 자연스럽기 때문입니다.”였지만 p2의 palace:신·flying:신:1에는 파군이 없다. 내면 p2 본문은 “천부와 지공, 타라 성향이 겹쳐 보여서”라고 했지만 근거는 palace:미와 star:자:minor:지공뿐이었다. 부처궁→노복궁 거문 화기는 실제 관계이며 연결 자체 오류라는 주장은 하지 않는다.
