# 선택한 궁의 설명과 기본 풀이

- 작성일·최종 갱신일: 2026-09-12
- 상태: 구현·코드 검증 완료, 브라우저 검증 대기

## 작업 개요와 요구사항

사용자는 궁을 선택하면 궁 자체의 설명과 자신의 기본적인 모습을 함께 볼 수 있도록 요청했다. 처음에는 상세 명반에만 적용했으나 후속 요청에 따라 간편 명반에서도 같은 궁을 선택해 쉬운 설명을 확인하도록 범위를 확장한다. REQ-03·04·05·07·08에 해당한다. AI 중지 결정과 궁 선택 시 추가 호출이 없는 흐름을 유지한다.

또한 ‘이 궁이 알려주는 것’, ‘내 명반에서 읽는 모습’, ‘별에서 읽는 태도’, ‘생활에 적용해보기’처럼 추상적이거나 자미두수 지식을 전제하는 제목을 일반 사용자가 이해할 수 있는 질문과 생활 언어로 바꾼다.

## 결정과 근거

간편·상세 명반은 같은 Jotai 선택 atom과 같은 명반 데이터를 사용한다. 두 화면에 별도의 선택 로직이나 풀이 데이터를 만들지 않고, 기존 궁별 설명 컴포넌트에서 상세 별 목록만 선택적으로 표시한다.

궁을 삶의 영역으로, 중심 별을 그 영역에서 나타나는 기본적인 모습의 근거로 설명한다. 화면 제목은 다음 순서로 통일한다.

1. 어떤 생활 영역을 보여주나요?
2. 이 영역에서 나는 어떤 모습인가요?
3. 별 이름 대신 ‘방향을 세우고 책임지려는 모습’처럼 뜻을 바로 알 수 있는 특징 제목
4. 생활에서는 어떻게 활용하면 좋을까요?

별 이름은 특징 제목에서 제거하고 ‘풀이 근거’로 분리한다. 12궁의 생활 맥락·실천 조언과 14주성의 기본 모습·균형 문구는 콘텐츠로 관리한다. 궁별 맥락과 주성의 기본 의미를 연결한 서비스 작성 문장이며, 168개 궁·별 조합의 정밀 풀이가 검증된 것으로 소개하지 않는다.

주성이 없으면 의미를 임의로 만들거나 맞은편 궁의 별을 빌리지 않는다. 여러 주성이 있으면 각 별의 의미를 따로 표시한다. 사화·밝기·보조성·삼방사정을 종합한 해석은 이 기본 풀이에 포함하지 않는다. 가족·배우자의 인격이나 재산·질병을 단정하지 않는다.

## 변경 내용과 영향

- `chart-ring.tsx`: 간편·상세 명반의 열두 궁을 모두 버튼으로 표시하고 동일한 선택 상태와 접근성 속성을 사용한다.
- `chart-result.tsx`: 간편 명반 바로 아래에 선택한 궁의 쉬운 풀이를 표시한다.
- `palace-detail.tsx`: 쉬운 궁 설명은 두 화면에서 공유하고 간지·주성·보조성·사화 목록은 상세 화면에서만 표시한다.
- `palace-reading-rules.ts`: 14주성마다 별 이름 없이 뜻을 바로 알 수 있는 특징 제목을 추가한다.
- `palace-reading.ts`와 UI: 전문 용어 중심 문장과 네 개 제목을 생활 언어로 교체하고 별 이름은 풀이 근거로 이동한다.

기존 궁·별·사화 툴팁, 상세 별 목록, 신궁 표시와 상세 전용 명반 요약은 유지한다. 원본 출생 정보나 외부 호출 없이 현재 명반 데이터로 즉시 전환한다.

## 검증

12궁의 실제 별 대조, 선택한 궁의 맥락 전환, 주성 없음·동명이 보조성 구분, 여러 주성의 개별 풀이 테스트를 유지하고 쉬운 특징 제목이 제공되는지 추가 검사했다. 간편 명반의 12개 선택 버튼과 쉬운 풀이 영역 연결, 상세 별 목록 제외를 정적 렌더링으로 검사한다.

변경 파일 포맷, ESLint, Next.js route typegen, TypeScript 검사와 전체 테스트 220개가 통과했다. 브라우저에서는 간편·상세 명반에서 서로 다른 궁을 선택했을 때 같은 선택 상태가 유지되고, 간편 화면에 기술적인 별 목록이 중복되지 않는지 확인할 예정이다. 로컬 서버는 실행됐지만 클라우드 브라우저가 localhost 접근을 차단해 최종 동작·모바일 시각 검증은 수행하지 못했다.

단위 테스트는 전통 해석의 정확성이나 전문가 검토를 증명하지 않는다. 검증에 유료 AI를 호출하지 않는다.

## 요구사항 대조와 남은 작업

간편·상세 화면 모두 궁을 선택할 수 있으며 자미두수를 모르는 사용자도 제목만으로 각 설명의 역할을 이해할 수 있도록 바꿨다. 기존 상세 기능과 해석 범위는 유지한다. 궁·별 조합의 전문적인 종합 풀이와 독립 검토는 후속 개선으로 남긴다. 운영 AI 중지와 Supabase 연결 대기는 유지한다.
