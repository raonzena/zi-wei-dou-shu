# 선택한 궁의 설명과 기본 풀이

- 작성일·최종 갱신일: 2026-09-12
- 상태: 구현·코드·브라우저 동작 검증 완료

## 작업 개요와 요구사항

사용자는 상세 명반에서 궁을 선택하면 궁 자체의 설명과 사용자에 대한 설명을 함께 볼 수 있도록 요청했다. REQ-05·07·08의 상세 명반과 용어 설명에 해당한다. AI 중지 결정과 궁 선택 시 추가 호출이 없는 흐름을 유지한다.

## 결정과 근거

기존 상세 영역은 선택한 궁의 정의와 별 목록만 제공했다. 기존 용어집, 주성 기본 풀이와 iztro의 궁·14주성 설명을 확인했다. 궁을 삶의 영역으로, 별을 그 영역을 돌아볼 때 참고하는 상징으로 구분한다. 선택 상태에는 기존 Jotai atom을 그대로 사용한다.

12궁의 생활 맥락·설명·실천 조언과 14주성의 기본 태도·균형 문구를 콘텐츠로 관리한다. 궁별 맥락과 주성의 기본 의미를 연결한 서비스 작성 문장이며, 168개 궁·별 조합의 정밀 풀이가 검증된 것으로 소개하지 않는다. 다른 궁의 별이나 AI의 주제별 해석 문단을 해당 궁의 풀이로 가져오지 않는다.

주성이 없으면 의미를 임의로 만들거나 맞은편 궁의 별을 빌리지 않는다. 여러 주성이 있으면 각 별의 의미를 따로 표시한다. 사화·밝기·보조성·삼방사정을 종합한 해석은 이 기본 풀이에 포함하지 않으며 화면에서 범위를 짧게 밝힌다. 가족·배우자의 인격이나 재산·질병을 단정하지 않는다.

## 변경 내용과 영향

- `palace-reading-rules.ts`: 궁별 생활 맥락과 주성별 기본 의미·실천 문구.
- `domain/interpretation/palace-reading.ts`: 선택한 궁에 실제 놓인 주성만 골라 설명 데이터 생성.
- `features/interpretation/palace-reading.tsx`: ‘내 명반에서 읽는 모습’과 ‘생활에 적용해보기’ 표시.
- `palace-detail.tsx`: ‘이 궁이 알려주는 것’과 사용자 기본 풀이를 별 목록 앞에 연결.

기존 궁·별·사화 툴팁, 별 목록, 신궁 표시와 상세 전용 명반 요약은 유지한다. 원본 출생 정보나 외부 호출 없이 현재 명반 데이터로 즉시 전환한다.

## 검증

12궁의 실제 별 대조, 선택한 궁의 맥락 전환, 주성 없음·동명이 보조성 구분, 여러 주성의 개별 풀이 테스트 4개가 통과했다. `pnpm check`의 포맷·린트·타입 검사와 전체 테스트 224개가 통과했으며 유료 실호출 평가 1개는 건너뛰었다.

실행 중인 개발 서버의 브라우저에서 명궁·관록궁의 여러 주성, 재백궁의 단일 주성, 질액궁의 주성 없음 안내를 확인했다. 궁 선택에 따라 제목·설명·풀이·별 목록이 함께 갱신됐다. 간편 탭에서는 명반 판독 요약과 새 궁별 풀이가 모두 표시되지 않는 것도 확인했다. 별도 개발 서버를 띄우려던 시도는 기존 서버 잠금 때문에 종료되어 기존 localhost:3000 서버로 검증했다.

새 풀이에는 외부 호출이 없고, 검증에 유료 AI를 호출하지 않았다. 단위 테스트는 전통 해석의 정확성이나 전문가 검토를 증명하지 않는다. 모바일 화면의 시각 검증은 이번에 수행하지 않았다.

## 요구사항 대조와 남은 작업

궁의 설명과 실제 배치에 따른 기본 풀이를 함께 제공하며 기존 상세 기능을 유지한다. 사용자 요구를 삭제하거나 축소한 항목은 없다. 해석은 현재 주성의 기본 의미 범위이며 궁·별 조합의 전문적인 종합 풀이와 독립 검토는 후속 개선으로 남긴다. 운영 AI 중지와 Supabase 연결 대기는 유지한다. 배포는 이번 작업에 포함하지 않는다.
