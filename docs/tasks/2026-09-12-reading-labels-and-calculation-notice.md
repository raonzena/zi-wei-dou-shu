# 계산 기준 안내 통합과 유월 제목 간소화

- 작성일: 2026-09-12
- 상태: 완료 — 로컬 검증 완료, 배포 전

## 작업 개요와 요구사항

[계산 기준 안내 통합 요구사항](../requirements.md)에 따라 해석을 읽는 도중 반복되는 엔진 이름과 달력 안내를 줄인다. 유월 해석 제목은 월만 표시하며 윤달의 서로 다른 해석 구간은 구분한다.

## 결정과 근거

사용자가 제시한 AiExplanation의 제목은 서버의 facts.references를 사용한다. 이 표시 문구를 간소화해 해석 제목과 유월 근거 표가 같은 이름을 사용하도록 한다. 평달은 ‘1월’, 윤달은 ‘윤6월 전반·후반’으로 표시한다. 기간 ID, part, dayRange, 월 순서와 AI 검증 계약은 유지한다. 같은 윤달 두 구간을 합치거나 양력 월로 바꾸지 않는다.

CalculationNotice를 간편·상세 탭 밖, 결과 페이지 마지막에 배치해 어느 탭과 AI 성공·실패·비활성화 상태에서도 동일한 계산 안내를 제공한다. 계산 출처와 한국 음력·양력과의 차이는 바로 보이며, 나이·연도 경계·윤달 일자 등 세부 정책은 펼쳐볼 수 있다. 기존 계산 자료의 제공·미제공 범위는 해당 자료 옆에 유지한다.

## 변경 내용과 영향

유년·유월 참조 제목, 11단계 범위 안내, 유월 목록 도입부, 대한·밝기 자료의 중복 계산 안내를 정리했다. 유년·유월 툴팁은 용어 뜻을 설명하고 세부 기준은 하단을 안내한다. 입력 화면의 AI 외부 전송 문단에서 중복 달력 문장을 제거했으며 같은 화면 하단의 상세 계산 기준과 데이터 전송 안내는 유지한다. 기본 풀이의 저작물 출처 링크는 반복 계산 안내와 목적이 달라 보존한다.

이전 로고 작업과 진행 중이던 문구 변경은 유지한다. 커밋에는 기존 작업 트리의 로딩 제목, 설명 재시도 버튼, 서비스 오류 안내에서 반복되는 AI 표기를 줄인 변경도 함께 포함한다. 외부 AI 전송 안내와 해석 주체 고지는 유지한다. 엔진·프롬프트·AI 모델·데이터·계산 규칙은 이번 변경 대상이 아니다.

## 검증

기존 6개 고정 사례에서 월 제목 형식과 유년 제목을 검사하고, 윤달 전반·후반의 독립된 키·표시 이름·순서 검증을 유지한다. pnpm check(203개 테스트 통과, 실호출 테스트 1개 기본 제외), pnpm build, git diff --check를 통과했다. AI를 비활성화한 운영 빌드에서 실제 계산 후 유월 표의 1월~12월 제목과 공통 footer 1개를 확인했다. 상세 탭으로 전환해도 같은 하단 안내가 유지됐다. AI 유월 제목은 검증한 같은 facts.references를 사용하며 실제 AI 생성은 반복하지 않았다. 유료 AI 호출은 하지 않는다.

## 요구사항 대조

계산 정책 고지를 삭제하지 않고 공통 하단으로 옮긴 사용자 승인 변경이다. 기준 문구를 반복 표시하도록 되어 있던 이전 문서의 화면 설명은 이번 결정으로 대체한다. 윤달 구간 포함 전체 유월 해석과 근거 자료를 유지한다.

## 남은 문제와 추후 개선점

이미 생성된 AI 문장 자체의 표현은 다시 생성하거나 임의 수정하지 않는다. 이번 변경은 서버가 표시하는 제목·고정 안내에 적용된다.
