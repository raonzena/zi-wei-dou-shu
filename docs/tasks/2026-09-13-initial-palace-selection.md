# 왼쪽 상단 궁 기본 선택

- 작성일: 2026-09-13
- 상태: 완료

## 작업 개요와 요구사항

사용자는 왼쪽 상단이 복덕궁으로 고정되어 있다면 해당 궁을 처음 선택하도록 요청했다. 실제 positions에서는 왼쪽 상단이 지지 사이며 궁 이름은 고정되지 않는다. 이를 안내하고 위치를 기준으로 초기 선택하도록 변경한다.

## 결정과 근거

배치 좌표가 [1, 1]인 궁을 기본값으로 사용한다. 표시 강조와 궁별 해석에 같은 선택 함수를 적용하고 직접 선택한 index를 우선한다. 계산 규칙은 바꾸지 않는다.

## 변경 내용과 영향

기존 명궁 기본 선택을 왼쪽 상단 선택으로 바꿨다. 종합 풀이와 상세 명반의 선택 상태는 공유한다. 요구사항과 화면 흐름을 갱신했다.

## 검증

궁 선택 테스트 5개와 타입 검사를 통과했다. 궁 이름이 달라도 왼쪽 상단을 선택하고, 수동 선택 시 표시 강조와 해석 대상이 일치하는 것을 검증했다. 브라우저 시각 검증과 AI 호출은 수행하지 않았다.

## 요구사항 대조

왼쪽 상단의 실제 궁을 선택한다. 복덕궁이 항상 해당 위치라는 전제는 코드와 달라 사용자에게 바로잡아 안내했다.

## 남은 문제와 추후 개선점

이번 기본 선택 변경에 미결정 사항은 없다.
