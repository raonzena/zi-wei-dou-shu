# 기본 풀이와 AI 해석의 쉬운 문장 적용

- 상태: 구현·검증 완료
- 관련 요구사항: REQ-04 해석, REQ-07 용어 설명, 사용자 쉬운 문장 적용 요청

## 결정과 근거

사용자가 제공한 예시의 일상적인 문체와 전문 용어 최소화 지침을 적용한다. AI 서비스 지침에 요청 문장을 그대로 추가하고 처음 등장하는 용어를 문장 안에서 설명하도록 보완했다. 기존 사용자 상담 프롬프트 원문과 12단계 출력 구조는 유지한다. 프롬프트 버전은 user-consultation-v7이다.

BasicReading은 생활 속 태도를 제목으로 먼저 보여주고 별 이름은 근거로 표시한다. 14개 별의 기존 의미를 쉬운 문장으로 다듬었으며 기본 풀이 버전은 ming-major-v2다. 명궁·주성·동궁 등을 알아야 읽을 수 있던 소개와 빈 결과 안내를 풀어 썼다. 계산 위치와 상세 범위는 접힌 출처 영역에서 확인한다. 별 이름과 명궁의 용어 설명은 유지한다.

예시의 직업·관계·금전 해석이나 복합 별 조합의 판단을 규칙 기반 풀이에 복사하지 않는다. 기존 계산 근거는 명궁의 주요 별에 한정되므로 문체를 개선하는 과정에서 근거 없는 해석을 추가하지 않는다. 예시의 출생 정보는 코드·평가 사례에 저장하지 않는다.

## 검증과 요구사항 대조

`pnpm check`의 포맷·lint·타입 및 기존 테스트 197개가 통과했다. 유료 검사 1개는 기본 설정대로 건너뛰었다. `pnpm build`도 통과했다. 문구를 그대로 복제하는 테스트는 추가하지 않았다.

기존 요구사항의 근거·출처·전문 용어 설명을 유지하고 본문 가독성을 개선했다. 기존 품질 개선 변경 위에 적용하며 유료 AI 호출은 수행하지 않는다. 실제 생성 문체 개선 여부와 기존 의미 오류의 해결 여부는 이번 문구 변경만으로 검증됐다고 판단하지 않는다.

## 추후 개선점

복합 배치 및 주제별 기본 풀이 확장은 검증된 해석 기준이 마련된 뒤 별도 진행한다. AI 내용의 정확성 문제는 기존 품질 평가 미통과 상태로 남아 있다.

## fluent-korean 지침에 따른 후속 문장 수정

사용자 요청으로 전역 AGENTS.md에 등록된 fluent-korean 지침을 읽고 basic-reading-rules의 제목·설명·질문 14세트를 수정했다. 사용자에게 표시하는 문구에 적용하라는 명시적 요청에 따라 작업했으며 코드 식별자와 주석은 유지했다. ‘모습과 연결됩니다’라는 간접적인 표현을 각 별이 무엇을 뜻하는지 설명하는 문장으로 바꾸었다. 제목에는 필요한 조사를 넣고 질문에서는 대상과 상황을 구체적으로 밝혔다. 기존 의미를 설명하는 일상적인 예시만 사용했으며 성향을 확정하거나 새로운 예측을 추가하지 않았다.

REQ-04·07과 대조해 해석 범위·출처·용어 설명이 유지됨을 확인했다. 기본 풀이가 아직 커밋 전인 ming-major-v2의 문구를 다듬는 작업이므로 버전은 유지한다. 유료 AI 호출은 하지 않는다.

후속 검증: 기본 풀이 테스트 6개가 통과했고 수정 파일의 포맷 및 git diff --check를 확인했다.
