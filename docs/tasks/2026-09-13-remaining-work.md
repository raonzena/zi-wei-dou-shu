# 공유 구현 후 남은 작업 정리

- 작성일: 2026-09-13
- 상태: 정리 완료 (후속 구현·운영 검증은 미수행)

## 작업 개요와 요구사항

사용자 요청에 따라 requirements.md의 미구현 범위와 출시 수용 기준, screen-flow.md의 미검증 항목, 최근 작업 기록을 대조했다. 요구사항을 변경하지 않는다.

## 결정과 근거

AI 비활성 상태에서의 출시 점검을 먼저 진행하고, 의미 품질 보완 후 AI 재개 여부를 판단하는 순서를 제안한다. 이는 우선순위 제안이며 새 기능의 구현 승인이 아니다.

## 남은 작업과 우선순위

1. 운영 반영 확인과 실제 기기 검증: 최신 커밋의 CI·Vercel 배포 상태, 결과 생성·다른 브라우저 복원·두 탭 공유·만료 및 오류 화면을 확인한다. 모바일·태블릿의 네이티브 공유, 취소, 토스트와 최종 버튼 배치·명반 가독성을 확인한다.
2. 계산 검증 확대: 독립 기준 명반과 출생 시각·달력 경계 사례를 추가 대조한다. 늦은 자시·윤달 예외는 현재 확정한 iztro 정책을 유지한다.
3. AI 의미 품질 보완: 인용한 궁의 연결 이유, 문단 근거와 조언의 대응, 참조 문단에 없는 별을 조언 이유에 사용하는 문제를 개선한다. 실제 일곱 분야의 문장 품질을 필요한 최소 호출로 평가하고 실패 응답을 공개한다. 운영 AI는 검증 후 재개를 결정한다.
4. 후속 범위: 별 설명의 추가 번역·전문가 검수, 진행 중 작업 복원, 별도 공유 해제. 회원가입·결제·궁합·자유상담·이미지 다운로드·다국어 UI는 첫 출시 제외 설계안으로 유지한다.

## 검증과 현재 상태

관련 요구사항·화면 흐름·공유/토스트/종합 풀이/별 콘텐츠 작업 문서와 배포 workflow를 읽었다. 로컬 main과 저장된 origin/main 참조는 모두 최신 커밋 5b5779f이며 차이는 0개다. 원격을 새로 조회하거나 실제 CI·배포 성공을 확인하지 않았으므로 배포 완료로 단정하지 않는다. 공유 직전 검증 기록은 279개 테스트 통과와 빌드 통과다. 이번 정리에서는 테스트·실제 AI 호출·배포를 실행하지 않았다.

## 요구사항 대조와 영향

기존 구현 완료 항목과 미검증·후속 항목을 구분했다. 코드·DB·요구사항 변경은 없으며, 이 페이지와 작업 목록만 추가한다.
