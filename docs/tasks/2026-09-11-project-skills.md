# 프로젝트 스킬 등록

- 작성일: 2026-09-11
- 상태: 완료

## 작업 개요와 결정

사용자가 추가된 `.agents/skills`를 커밋하도록 요청했다. 스킬 14개를 구성하는 파일 52개와 동일한 설치 목록을 기록한 `skills-lock.json`을 함께 등록한다. 설치된 파일을 실행하거나 지침 내용을 변경하지 않고 원본을 보존한다.

## 검증

각 스킬의 SKILL.md 디렉터리 이름과 잠금 파일의 14개 항목이 일치함을 확인했다. 잠금 파일의 JSON 파싱과 포함된 Python 스크립트의 AST 구문 검사가 통과했다. 외부 저장소와 해시를 재검증하거나 스킬 스크립트를 실행하지 않았다.

앞선 전체 check에서 확인한 스킬 문서 42개의 Prettier 경고는 남아 있다. 설치 원본 보존을 위해 이번 커밋에서 일괄 포맷을 변경하지 않았다. 앱 코드와 의존성은 바뀌지 않아 앱 테스트·빌드를 반복하지 않았다.

## 요구사항 대조와 후속

requirements.md의 서비스 기능·계산 정책·개인정보 처리 요구사항과 달라지는 항목은 없다. 이번 작업은 개발 보조 파일 등록이며 새로운 제품 기능 구현으로 집계하지 않는다. 스킬 내용의 품질 검토와 포맷 정책 정리는 별도 작업으로 남긴다.
