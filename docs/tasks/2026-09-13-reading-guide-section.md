# 명반 읽기 안내 섹션 구분

- 작성일: 2026-09-13
- 최종 갱신일: 2026-09-13
- 상태: 완료

## 작업 개요

‘명반을 읽는 방법’이 앞의 풀이와 이어져 보이지 않도록 별도 섹션임을 시각적으로 드러낸다.

## 요구사항

사용자가 요청한 섹션 구분을 적용한다. 두 보기에서 읽기 안내를 제공하는 기존 요구사항은 유지한다.

## 결정과 근거

현재 ReadingGuide는 이미 section과 제목 연결을 사용하지만 외곽 구분선이 없다. 기존 colors.line과 여백 단위를 사용해 상단 구분선, 바깥 여백 2rem, 안쪽 여백 1.5rem을 추가한다. baseline-ui 지침에 따라 기존 디자인과 의미 구조를 유지한다.

## 변경 내용과 영향

ReadingGuide 전용 스타일과 제목 상단 여백을 추가했다. 같은 컴포넌트를 쓰는 종합 풀이와 상세 명반에 함께 적용된다. 문구, 순서와 접힘 동작은 변경하지 않는다.

## 검증

타입 검사와 git diff --check를 통과했고 변경 파일을 Prettier로 정리했다. 스타일 변경이므로 새 테스트는 추가하지 않았다. 브라우저 시각 검증은 수행하지 않았다.

## 요구사항 대조

요구사항에 읽기 안내의 시각적 구분을 기록했다. 안내 내용과 두 보기의 기능은 유지한다.

## 남은 문제와 추후 개선점

이번 섹션 구분 범위에 추가 기능이나 미결정 사항은 없다.
