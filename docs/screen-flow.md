# 화면 흐름

작성일: 2026-09-11

상태: [확정 요구사항](requirements.md)을 구현하기 위한 화면·라우트 설계안

## 1. 전체 흐름

```text
출생 정보 입력
  ├─ 입력 오류 → 해당 필드 수정
  └─ 유효한 입력 제출
       ↓
전용 로딩 화면
  ├─ 명반 계산 실패 → 입력 수정 / 원인에 따른 안내
  ├─ 해석 생성 실패 → 재시도 / 입력으로 돌아가기
  └─ 완료 → 간편 결과 (기본)
               ↕ 탭 전환 — 재계산·재생성 없음
             상세 명반

간편 결과 또는 상세 명반
  → 공유 내용 확인 → 링크 공유
  → 수신자는 공유 전용 결과 조회 (공유한 탭으로 진입)
```

## 2. 제안 경로

| 경로                              | 용도           | 새로고침 / 접근 조건                                 |
| --------------------------------- | -------------- | ---------------------------------------------------- |
| `/`                               | 출생 정보 입력 | 현재 입력 상태의 보존 범위는 소유권 설계와 함께 확정 |
| `/reports/[reportId]/progress`    | 결과 생성 로딩 | 서버 상태 조회; 완료면 결과, 실패면 재시도 UI        |
| `/reports/[reportId]`             | 간편 결과      | 소유권 확인; 생성 중이면 progress로 안내             |
| `/reports/[reportId]?view=detail` | 상세 명반      | 같은 결과에 대한 보기 모드만 변경                    |
| `/s/[shareToken]`                 | 공유 간편 결과 | 활성 공유만 조회; 비공개 필드 제외                   |
| `/s/[shareToken]?view=detail`     | 공유 상세 명반 | 같은 공개 결과의 상세 보기                           |

위 표는 최종 결과 흐름을 위한 경로 설계안이다. 현재 구현 범위는 문서 마지막 절에 정리했다. reportId는 결과를 구분하는 식별자이며, 이 값을 아는 것만으로 접근 권한이 생기지는 않는다. 잘못된 view 값은 간편 보기로 정규화하는 안이다. URL에 출생 정보를 넣지 않는다.

## 3. 출생 정보 입력

입력 화면에는 다음 순서로 정보를 표시한다.

1. 서비스 제목, 1900년 이후 대한민국 출생 지원 범위와 입력 목적 안내
2. 생년월일 및 양력·음력 선택
3. 음력 선택 시 윤달 여부
4. 출생 시각과 입력 도움말: 당시 기록된 현지 시각 입력, 역사적 시간 보정·진태양시 미적용 안내
5. 계산에 필요한 성별
6. 개인정보 이용·보관 안내
7. 결과 보기 버튼

입력 변경은 입력 화면의 상태를 갱신한다. 제출 시 서버 검증을 거쳐 결과 식별자를 얻고 로딩 화면으로 이동한다. 결과 생성의 구체적인 실행 방식은 AI 지연과 배포 환경 검증 후 결정한다.

## 4. 로딩 화면

로딩 화면에는 진행 안내 문구와 로딩 표시를 제공한다. 실패한 경우에는 사용자가 복구를 위해 할 수 있는 행동을 안내한다.

| 상태         | 표시                                     | 다음 상태                |
| ------------ | ---------------------------------------- | ------------------------ |
| 명반 계산 중 | 명반을 계산하고 있습니다                 | 해석 생성 중 / 계산 실패 |
| 해석 생성 중 | 명반을 바탕으로 해석을 작성하고 있습니다 | 완료 / 생성 실패         |
| 완료         | 결과로 이동                              | 간편 결과                |
| 실패         | 원인에 맞는 안내                         | 재시도 / 입력 수정       |

위 상태 이름은 사용자가 화면에서 확인할 진행 단계를 설명한다. 실제 DB enum이나 작업 큐의 구조를 확정한 것은 아니다. 브라우저를 닫았다고 서버 작업이 취소됐다고 가정하지 않는다. 처리 중 새로고침하면 기존 상태를 조회하고, 중단된 작업은 실패·재시도 가능한 상태로 정리한다.

라우트 전환용 로딩 UI와 생성 작업의 로딩 화면을 구분한다. 진행 표시는 서버가 확인한 단계만 사용한다.

## 5. 결과 공통 레이아웃

```text
결과 제목
[간편 풀이] [상세 명반]                 [공유하기]
─────────────────────────────────────────────
선택한 탭의 내용
```

- 처음에는 간편 풀이가 선택된다.
- 탭은 선택 상태·패널 관계를 표현하고 키보드 탐색을 지원한다.
- 탭 선택은 URL로 표현해 직접 링크와 브라우저 이동을 지원한다.
- URL의 보기 상태를 Jotai atom에 중복 저장하지 않는다.
- 전환 시 저장된 명반·해석을 재사용한다.
- 공유받은 결과에서도 두 탭을 볼 수 있지만 소유자의 관리 기능은 제공하지 않는다.

## 6. 간편 풀이

```text
간소화된 명반
  12궁의 관계를 유지
  궁 이름·주요 별·명궁/신궁 중심 (목록 확정 필요)

해석 요약
주제별 해석
  성향 / 일과 강점 / 관계 / 재물 (주제 확정 필요)
  전문용어 → 용어 설명
```

사용자가 요청한 명반 → 하단 해석 순서를 유지한다. 요약·주제 분류는 해석 내부의 읽기 구조다. 과도한 정보는 상세 명반에 배치하되 간편·상세가 서로 다른 명반을 보여주지 않도록 한다.

## 7. 상세 명반

```text
상세 명반
  궁·주성·검증한 보조성·사화 등

선택한 궁 또는 별의 정보
  한글 이름·한자·용어 설명
  연관 정보 (검증된 범위)
```

모바일에서는 명반 전체의 관계와 선택한 궁의 읽기 편의성을 함께 검증한다. 세부 항목을 읽기 어려운 크기로 일괄 축소하지 않는다. 복잡한 확대·이동 기능은 필요가 확인된 경우에만 도입한다.

## 8. 용어 설명 상호작용

| 입력 방식 | 열기                                      | 닫기                                                     |
| --------- | ----------------------------------------- | -------------------------------------------------------- |
| 마우스    | 용어 hover 또는 클릭                      | hover 설명은 관련 영역 이탈, 클릭 설명은 바깥 클릭 / Esc |
| 키보드    | 용어 focus; 클릭형 트리거는 Enter / Space | Esc, focus 이동에 맞는 처리                              |
| 터치      | 용어 탭                                   | 바깥 영역 탭 또는 트리거 재선택                          |

클릭할 요소가 없는 짧은 설명에는 tooltip을 사용한다. 설명 안에 링크나 버튼이 필요하다면 popover를 사용한다. 선택할 UI 라이브러리의 문서와 접근성 동작을 확인하고 상태 전이를 일관되게 구현한다.

## 9. 공유 흐름

1. 결과 화면에서 공유하기를 누른다.
2. 공개될 명반·해석과 숨길 정보의 범위를 확인한다.
3. 공유를 실행하면 공개용 토큰을 생성하거나 현재 활성 링크를 사용한다.
4. 현재 탭을 포함한 링크를 복사하거나 시스템 공유로 전달한다.
5. 수신자는 생성 없이 저장된 공개 결과만 조회한다.
6. 소유자가 공유를 해제하면 기존 링크는 결과를 반환하지 않는다.

시스템 공유 창 취소는 생성 오류로 취급하지 않는다. 링크 복사 성공은 실제 복사 완료 후 알린다. 메신저 미리보기에는 비공개 정보나 원본 결과 접근 권한을 포함하지 않는다.

## 10. 화면 흐름 검증표

- [ ] 유효·무효 입력과 음력·윤달 조건
- [ ] 실제 생성 중 상태, 빠른 완료, 생성 실패, 재시도
- [ ] 중복 제출 및 로딩 도중 새로고침
- [ ] 첫 간편 진입과 상세 직접 링크
- [ ] 탭 전환·뒤로 가기·새로고침 시 보기 상태
- [ ] 모바일·데스크톱의 명반 가독성
- [ ] 용어 hover·터치·키보드 조작
- [ ] 양쪽 탭의 공유, 복사 실패, 시스템 공유 취소
- [ ] 다른 브라우저의 공개 결과 조회
- [ ] 소유권 없는 원본 접근 차단
- [ ] 공유 해제·결과 삭제·만료 링크

## 현재 구현 단계

루트 페이지에서 입력 → 서버 계산 중 화면 → 실제 12궁·주성 미리보기 → 입력 수정 흐름을 연결했다. 이 단계는 reportId 기반 영속 결과·해석·상세·공유 경로의 구현 완료가 아니다. 새로고침 후 결과를 복원하는 기능은 저장 방식과 소유권을 설계한 뒤 구현한다. 위에서 제안한 라우트는 후속 구현을 위한 설계로 유지한다.

## 간편·상세 명반의 현재 동작

루트 페이지에서 계산한 명반을 간편·상세 탭으로 확인한다. 간편 탭은 12궁과 주요 별을 보여주고 그 아래에 공통 읽는 법을 안내한다. 상세 탭은 같은 배치에서 궁을 선택하면 그 아래에 간지와 표시 범위에 해당하는 별, 사화를 보여준다. 선택한 궁은 탭 전환 시 유지하고 새 계산에서는 명궁으로 초기화한다.

보기 모드는 `?view=detail`로 표현하며 값이 없거나 유효하지 않으면 간편 명반을 표시한다. 탭 전환과 브라우저 뒤로·앞으로 이동에 기존 계산 결과를 사용한다. 새 계산 결과는 간편 탭으로 시작한다. 결과를 저장하지 않으므로 URL만으로 결과를 복원하거나 공유할 수는 없다.

점선으로 표시한 용어는 클릭·hover·키보드 포커스로 설명을 확인한다. 팝오버 안에 출처 링크와 닫기 버튼을 제공한다. 최종 결과 라우트와 개인화 해석, 공유 흐름은 위 설계안에 따라 후속 작업으로 유지한다.

## 규칙 기반 기본 풀이의 현재 동작

간편 명반 아래에 명궁 주성의 기본 의미와 성찰 질문을 표시한다. 풀이 근거로 명궁의 지지 위치와 별을 보여주며, 전문용어는 기존 팝오버를 사용한다. ‘풀이의 범위와 출처’를 펼치면 미지원 범위와 참고 자료를 확인할 수 있다. 주성이 없는 경우와 동궁인 경우를 구분해 안내한다.

현재 서버 작업은 명반과 기본 풀이를 한 번에 준비한다. 별도 AI 단계나 가짜 진행률을 만들지 않는다. 입력 목적 문구도 기본 풀이를 포함하도록 갱신했다. 이전 절의 개인화 해석 미구현 기록 중 명궁 기본 설명은 이 단계에서 연결했으며, 전체 종합·주제별 해석과 영속 결과·공유는 여전히 미구현이다.

## AI 설명을 선택한 경우

입력에서 ‘기본 풀이를 AI 설명과 함께 보기’를 선택하면 외부 처리 안내를 확인한 뒤 제출한다. 선택하지 않으면 기존 기본 풀이 흐름을 사용한다. 선택한 경우 같은 서버 요청에서 명반·기본 풀이·AI 설명을 준비하고 결과로 이동한다.

간편 명반 하단의 기본 풀이 다음에 AI 설명을 표시하며 문단마다 원래 규칙의 의미를 함께 보여준다. 실패 상태에는 오류 안내를 표시하고, 일시적인 실패에만 ‘AI 설명 다시 시도’를 제공한다. 재시도 중 기본 풀이를 유지하고 중복 재시도·입력 수정은 막는다. 탭 전환은 가능하며 완료된 설명을 재생성하지 않는다.

## 사용자 프롬프트 적용 후 AI 결과

AI 선택 항목은 ‘12단계 AI 해석 함께 보기’로 표시한다. 간편 명반·기본 풀이 다음에 12단계별 펼치기 영역을 제공한다. 첫 단계는 기본으로 열고 서버가 전달한 12궁 표와 미제공 자료를 표시한다. 각 단계는 근거·용어 설명·해석·생활 점검과 자료 한계를 포함한다. 평생 흐름·대한·유년은 자료 필요 상태를 표시한다. 탭 재사용과 실패 재시도는 유지한다.

## AI 이용 한도 오류

크레딧·지출·사용량 한도에 도달한 경우에는 서비스 운영자의 확인이 필요함을 안내하고 재시도 버튼을 표시하지 않는다. 기존 명반과 기본 풀이는 유지한다. 일시적인 요청 속도 제한에는 기존 명시적 재시도를 제공한다.

## 명반 보충 자료 표시

AI 선택 안내에 명주·신주·밝기·대한·올해 유년의 외부 전송 범위를 고지한다. 원본 출생 정보는 보내지 않지만 대한의 나이·연도 구간으로 출생 연도를 추정할 수 있음을 안내한다. 결과의 첫 AI 요약에는 12궁 별의 밝기와 명주·신주, 전체 대한 표·올해 유년 사화·나이와 연도 기준을 표시한다. 시기 문단의 대한·유년 근거도 화면에서 확인한다. 유월과 아직 미지원인 판정 자료만 추가 분석 자료로 구분한다.

## 2026-09-12 — 유월과 확장 근거

입력 화면의 외부 전송 안내에 궁간 사화·격국 구조 검사·유월·유요를 포함한다. AI 첫 요약에서 올해 전체 유월 표, 대한·유년 유요, 48개 궁간 사화, 두 격국의 구조 검사를 각각 펼쳐볼 수 있다. 기본값은 닫힘이며 전문용어 설명을 제공한다. AI 11단계에서 모든 월 구간을 묶어 설명하고 해당 월의 근거를 표시한다. 월·일은 iztro 음력이라는 안내를 표 옆에 둔다.
