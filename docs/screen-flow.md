# 화면 흐름

최종 갱신일: 2026-09-12

상태: [확정 요구사항](requirements.md)을 구현하기 위한 현재 화면 흐름과 후속 설계

이 문서는 현재 유효한 화면 동작만 설명한다. 변경 전 흐름은 [작업 기록](tasks/README.md)과 Git 이력에서 확인한다.

## 1. 현재 구현 흐름

```text
출생 정보 입력
  ├─ 입력 오류 → 해당 필드 수정
  └─ 유효한 입력 제출
       ↓
명반 계산·해석 준비
  ├─ 계산 실패 → 원인 안내 / 입력 수정
  ├─ AI 실패 → 기본 풀이 유지 / 조건에 따라 재시도
  └─ 완료 → 간편 결과 (기본)
               ↕ 탭 전환 — 재계산·재생성 없음
             상세 명반
```

결과는 브라우저 메모리에만 유지한다. 현재는 URL만으로 결과를 복원하거나 공유할 수 없다.

## 2. 후속 결과·공유 경로 설계

| 경로                              | 용도           | 새로고침 / 접근 조건                                 |
| --------------------------------- | -------------- | ---------------------------------------------------- |
| `/`                               | 출생 정보 입력 | 현재 입력 상태의 보존 범위는 소유권 설계와 함께 확정 |
| `/reports/[reportId]/progress`    | 결과 생성 로딩 | 서버 상태 조회; 완료면 결과, 실패면 재시도 UI        |
| `/reports/[reportId]`             | 간편 결과      | 소유권 확인; 생성 중이면 progress로 안내             |
| `/reports/[reportId]?view=detail` | 상세 명반      | 같은 결과에 대한 보기 모드만 변경                    |
| `/s/[shareToken]`                 | 공유 간편 결과 | 활성 공유만 조회; 비공개 필드 제외                   |
| `/s/[shareToken]?view=detail`     | 공유 상세 명반 | 같은 공개 결과의 상세 보기                           |

위 경로는 저장·공유 구현을 위한 설계안이다. `reportId`는 결과 식별자일 뿐 접근 권한이 아니며 URL에 출생 정보를 넣지 않는다.

## 3. 출생 정보 입력

입력 화면에는 다음 순서로 정보를 표시한다.

1. 서비스 제목과 1900년 이후 대한민국 출생 지원 안내
2. 생년월일 및 양력·한국 음력 선택
3. 음력 선택 시 윤달 여부
4. 출생 시각과 당시 기록된 현지 시각 입력 안내
5. 계산에 필요한 성별
6. 개인정보, 외부 AI 처리, 운영 기록 보관 안내
7. 결과 보기 버튼

날짜와 시각은 목록 선택과 직접 입력을 지원한다. 성별은 남성이 기본값이며 출생 시각에는 기본값이 없다. 제출 시 클라이언트와 서버 검증을 거쳐 같은 요청에서 명반·기본 풀이·활성화된 AI 해석을 준비한다.

`AI_EXPLANATION_ENABLED=false`이면 외부 AI 호출을 하지 않고 관련 전송 안내를 숨기며 명반과 기본 풀이만 준비한다. 운영은 현재 이 상태다.

## 4. 로딩과 오류

| 상태         | 표시                                     | 다음 상태             |
| ------------ | ---------------------------------------- | --------------------- |
| 명반 계산 중 | 명반을 계산하고 있습니다                 | 해석 준비 / 계산 실패 |
| 해석 준비 중 | 명반을 바탕으로 해석을 작성하고 있습니다 | 완료 / 생성 실패      |
| 완료         | 결과로 이동                              | 간편 결과             |
| 실패         | 원인에 맞는 안내                         | 재시도 / 입력 수정    |

- 임의 진행률이나 연출을 위한 최소 대기 시간을 표시하지 않는다.
- AI 실패 시 계산한 명반과 기본 풀이는 유지한다.
- 일시적 제공자 오류에만 재시도 버튼을 표시한다. 크레딧·설정·운영 한도 오류에는 반복 재시도를 제공하지 않는다.
- 재시도 중에는 중복 재시도와 입력 수정을 막고 탭 전환은 허용한다.
- 현재 구현은 새로고침 후 작업 복원을 지원하지 않는다. 영속 작업 상태는 저장·소유권 설계 후 연결한다.

## 5. 결과 공통 레이아웃

```text
결과 제목
[간편 풀이] [상세 명반]
────────────────────────
선택한 탭의 내용
```

- 첫 결과는 간편 풀이가 선택된다.
- 탭은 선택 상태와 패널 관계를 표현하고 키보드 탐색을 지원한다.
- 보기 모드는 `?view=detail`로 표현하며 없거나 유효하지 않은 값은 간편 보기로 정규화한다.
- 탭 전환과 브라우저 뒤로·앞으로 이동에는 기존 계산 결과를 사용한다.
- 새 계산 결과는 간편 보기로 시작하고, 선택한 궁은 탭 전환 시 유지한다.

## 6. 간편 풀이

화면은 다음 순서로 표시한다.

1. 12궁 관계를 유지한 간소화 명반
2. 명궁 주성의 규칙 기반 기본 풀이
3. 활성화된 경우 AI 명반 해석
4. 공통 계산 기준 안내

간소화 명반은 궁 이름, 주요 별, 명궁·신궁과 오행국을 우선 표시한다. 기본 풀이는 ‘~하는 사람’ 제목과 성향·강점·주의점 세 문단으로 구성하며 성찰 질문은 표시하지 않는다. 주요 별이 없거나 둘인 경우에는 적용 범위를 구분해 안내한다.

간편 명반의 열두 궁은 모두 선택할 수 있다. 선택한 궁 아래에는 ‘어떤 생활 영역을 보여주나요?’, ‘이 영역에서 나는 어떤 모습인가요?’, ‘생활에서는 어떻게 활용하면 좋을까요?’ 순서로 쉬운 설명을 표시한다. 별 이름은 내용 제목으로 사용하지 않고 각 특징 아래의 풀이 근거로 구분한다.

### AI 명반 해석

```text
나의 명반 해석
  전체 요약 1~2문단
  핵심 성향
  일과 커리어
  돈
  관계와 배우자
  내면과 삶의 방향
  건강과 컨디션
  가족·대인관계
  한 줄로 정리하면
```

각 분야는 개인화된 제목과 1~3문단을 표시하며 필요한 경우에만 짧은 목록을 덧붙인다. 각 블록의 명반 근거는 기본적으로 접힌 영역에서 확인한다. 내부 근거 ID는 사용자 문장에 노출하지 않는다.

12단계 펼치기, 용어·해석·생활 점검의 반복 블록, AI가 작성한 대한·유년·유월 해석은 표시하지 않는다.

## 7. 상세 명반

상세 탭에는 다음 내용을 표시한다.

1. 상세 명반
2. 기본적으로 접힌 ‘명반 판독 요약’
3. 선택한 궁의 설명과 기본 풀이
4. 선택한 궁의 간지, 별, 사화 등 검증된 세부 정보
5. 공통 계산 기준 안내

명반 판독 요약은 서버 계산 자료이며 명궁·신궁·명주·신주·오행국, 궁·별·밝기·사화, 대한·유년·유월과 검증 범위의 확장 근거를 보여준다. AI 해석과 섞거나 간편 화면에 중복 표시하지 않는다.

궁을 선택하면 ‘어떤 생활 영역을 보여주나요?’ → ‘이 영역에서 나는 어떤 모습인가요?’ → ‘생활에서는 어떻게 활용하면 좋을까요?’ → 별 목록 순서로 갱신한다. 기본 선택은 명궁이며 실제 놓인 주성의 의미만 사용한다. 이 동작에는 재계산이나 AI 호출이 없다.

## 8. 용어와 근거 상호작용

| 입력 방식 | 열기                         | 닫기                              |
| --------- | ---------------------------- | --------------------------------- |
| 마우스    | 용어 hover 또는 클릭         | hover 영역 이탈 / 바깥 클릭 / Esc |
| 키보드    | 용어 focus, Enter 또는 Space | Esc 또는 focus 이동               |
| 터치      | 용어 탭                      | 바깥 영역 탭 또는 트리거 재선택   |

- 링크나 버튼이 있는 설명은 포커스를 지원하는 popover를 사용한다.
- 명반 근거 목록은 개수를 표시한 접힌 영역으로 제공하고 키보드로 펼칠 수 있다.
- 계산 근거와 사화 나열 같은 보조 문구는 10px로 표시하되 본문과 용어 팝업의 글자 크기는 유지한다.
- 계산 기준 안내는 결과 페이지 하단에 한 번만 표시한다.

## 9. 공유 흐름 — 미구현 설계

1. 간편 또는 상세 결과에서 공유하기를 누른다.
2. 공개될 명반·해석과 숨길 정보의 범위를 확인한다.
3. 공개용 토큰을 생성하거나 현재 활성 링크를 사용한다.
4. 현재 탭을 포함한 링크를 복사하거나 시스템 공유로 전달한다.
5. 수신자는 재생성 없이 저장된 공개 결과만 조회한다.
6. 소유자가 공유를 해제하면 기존 링크는 결과를 반환하지 않는다.

공유 버튼, 영속 결과와 공개 링크는 아직 구현하지 않았다.

## 11. 문서 갱신 원칙

- 이 문서에는 현재 유효한 화면과 상태 전이만 기록한다.
- 새 결정이 기존 흐름과 충돌하면 기존 절을 직접 수정하고 날짜별 후속 절을 추가하지 않는다.
- 변경 전 화면, 결정 이유, 검증 결과는 작업 문서와 Git 이력에서 확인한다.
