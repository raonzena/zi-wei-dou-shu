# 자미두수 — zi-wei-dou-shu

일반 사용자가 출생 정보를 입력해 간소화된 명반과 한국어 해석을 확인하는 웹 서비스다. 상세 명반을 탐색하고 결과를 공유하는 기능도 제공하는 것을 목표로 한다.

- 저장소: https://github.com/raonzena/zi-wei-dou-shu
- 기술 스택: pnpm, Next.js, TypeScript, Vitest, vanilla-extract, Jotai, Supabase

현재는 초기 설정과 계산 엔진의 1차 평가를 마치고, 출생 정보 검증과 시간 정규화를 거쳐 iztro로 명반을 계산하는 흐름을 연결했다. 독립 기준 명반의 일부 항목을 대조했으며, 입력 화면에서 실제 명반 미리보기까지 확인할 수 있다.

초기 엔진으로 iztro를 사용하고, 추후 필요한 명반 기능을 TypeScript로 직접 구현하기로 결정했다. 간편·상세 명반 탭과 궁 선택, 용어 설명을 연결했다. 명궁 주성의 규칙 기반 기본 풀이를 연결했다. 추가 계산 검증과 종합·주제별 해석, 결과 저장 및 공유 기능은 후속 작업으로 남아 있다.

## 실행 환경

- Node.js **24.x** (`.node-version`)
- pnpm **10.33.2** (`packageManager`)
- Next.js App Router, 개발·운영 빌드 모두 Webpack 사용

설치된 Node.js가 다른 버전이라면 사용하는 버전 관리 도구에서 Node.js 24로 전환한다. `engine-strict`로 지원하지 않는 런타임의 설치·실행을 차단한다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

기본 개발 주소는 http://localhost:3000 이다. 첫 화면에서 출생 정보를 입력하면 실제 명반 미리보기를 확인할 수 있다. 간편·상세 탭과 용어 설명을 사용할 수 있다. 명궁 주성의 기본 풀이를 제공하며, 결과 저장과 공유 및 종합·주제별 해석은 아직 연결하지 않았다.

## Supabase

SDK는 설치되어 있다. 첫 화면·빌드·테스트에 Supabase 환경변수는 필요하지 않다. 실제 연결은 소유권·보관 정책과 데이터 모델을 확정한 뒤 구현한다.

연결 단계에서 `.env.example`을 `.env.local`로 복사하고 프로젝트 값을 입력한다. `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`는 공개 키이고 `SUPABASE_SECRET_KEY`는 서버 전용 키다. 서버 키를 공개 환경변수에 넣지 않는다. `.env.local`은 Git에 포함하지 않는다.

## 현재 단계와 다음 작업

출생 입력 → 서버 검증·계산 → 간편·상세 명반과 용어 설명까지 연결했다. 초기 계산은 윤달 늦은 자시 예외까지 iztro를 따른다. 사용자는 추후 윤달과 늦은 자시가 겹칠 때의 처리가 개선되기를 원한다. 해당 규칙을 변경할 때는 날짜·시각 경계를 검증하고 계산 정책 버전을 갱신한다.

1. 명궁 기본 풀이를 바탕으로 동궁·주성 없는 명궁과 주제별 해석의 규칙·사례 검토를 확장한다. AI 설명은 연결했으며 실제 API 키 설정 후 한국어 품질과 근거 충실성을 평가한다.
2. 소유권·보관 정책을 정하고 결과 저장·복원·공유를 구현한다.
3. 추가 독립 명반·전체 경계·출시 수용 기준을 검증한다.

[입력·미리보기 작업 기록](docs/tasks/2026-09-11-birth-input-preview.md), [윤달 예외 조사와 최종 결정](docs/tasks/2026-09-11-leap-late-rat-policy.md)을 참고한다.

[간편·상세 명반 UI 작업](docs/tasks/2026-09-11-chart-result-ui.md)에 표시 범위와 검증 결과를 기록했다.

## AI 설명 실행

OpenAI 공식 SDK로 `gpt-5.4-mini-2026-03-17`을 호출한다. 프로젝트의 `.env.local`에 서버 전용 `OPENAI_API_KEY`를 설정한 뒤 서버를 다시 시작한다. 키는 채팅·저장소·NEXT_PUBLIC 환경변수에 넣지 않는다. 기본 풀이와 빌드·모의 API 테스트에는 키가 필요하지 않다.

입력 화면에서 ‘12단계 AI 해석 함께 보기’를 선택하면 실제 API 요청이 발생하며 계정의 사용 요금이 적용된다. 현재 저장소에서는 실호출을 검증하지 못했다. 키가 없으면 기본 풀이와 AI 서비스 준비 안내를 표시한다.

요청은 90초, 최대 출력 16,000토큰으로 제한하고 SDK 자동 재시도를 끈다. AI에는 12궁·표시 범위의 별·생년사화와 궁의 연결 관계를 보낸다. 출생 정보와 미검증 밝기·운한 데이터는 보내지 않는다. 사용자 제공 12단계 프롬프트를 사용하며, 시기별 분석은 자료 필요 상태로 제공한다. `store: false`를 사용하되 제공자 측 모든 보관을 배제한다고 간주하지 않는다.

공개 출시 전에 호출자별 요청 제한과 전체 사용량 통제, 배포 환경 시간 제한, 실호출 품질 평가가 필요하다. 브라우저의 중복 클릭 방지는 서버 사용량 제한을 대신하지 않는다. [AI 설명 작업 기록](docs/tasks/2026-09-11-ai-explanation.md)을 참고한다.

현재 AI 프롬프트와 지원 범위는 [사용자 상담 프롬프트 적용 기록](docs/tasks/2026-09-11-user-consultation-prompt.md)을 따른다.
